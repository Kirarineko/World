# 徐海 · 经历

---

## 一、 明川求学与香橼岁月（早年—承明历57年）

徐海出生于承明大陆首都昭明京东侧的卫星都会——**明川**。

18 岁那年，年轻的徐海远渡重洋，考入北星洲北辰京的高等学府攻读计算机与电子工程相关专业。毕业后，他顺利留在了北星洲，加入当时在个人电脑领域如日中天的老牌先驱巨头——**“香橼计算机”**。

在香橼计算机任职的数十年间，徐海从一线工程师一路成长为核心产品线的负责人，主导了多款个人电脑（PC）产品的架构与工业设计。他的产品生涯充满了戏剧性的张力：他曾敏锐捕捉市场痛点，接连打造出几代风靡一时的现象级爆款机型；但与此同时，他也有更大比例的激进尝试或超前设计因市场水土不服、供应链成本过高或内部派系倾轧而石沉大海。这段长达数十年的大厂摸爬滚打，为他积攒了极其深厚的软硬件工程经验与商业直觉。

承明历 57 年，北星洲爆发严重的金融危机，香橼计算机业绩暴跌并启动大规模重组裁员。年近六旬、为公司奉献了大半辈子的徐海，在这场冷酷的裁员潮中被一纸通知解雇。

## 二、 择址星月湾与雷云初创（承明历57年—64年）

遭遇晚年失业的徐海没有在北星洲消沉养老。他收拾行囊回到故土承明大陆，决定倾尽毕生积蓄与经验再干一番事业。

在选定创业落脚点时，当时的承明大陆有两个新兴备选：一个是刚刚启动新城改造、被许多激进投资者普遍看好的西北古邑**望城**；另一个则是东南沿海信息技术正在蓬勃发展、社会环境宽松稳定的**星月湾**。经过严密的实地考察，经验老道的徐海认为当时的望城尚处起步初期，基建与产业配套仍有较高不确定性，最终拍板选择了发展势头稳健、相对更为保险的星月湾。

在星月湾，这位年近花甲的行业老兵结识了四位刚刚从昭明京承明大学计算机系毕业、意气风发的高材生——23 岁的**李云舟**、24 岁的**浅云舒**，以及他们的同窗好友**李焕**与**王昌**。

老辣的产业视野与年轻顶尖的技术才华一拍即合。经过一段时间的深入交流，五人决定合伙创业。承明历 59 年（公开日同年），**雷云科技**在星月湾正式创立，以企业级云服务（钢云）为主业，利用星月湾清冽的地下山泉作为数据中心自然冷却源，迅速在信息化浪潮中站稳了脚跟。

## 三、 商业帝国崛起（承明历65年—80年）

在徐海的掌舵与四位年轻合伙人的并肩作战下，雷云踩准了随后二十年的每一个时代节拍：

- **网购与支付飞轮（65—67年）**：承明历 65 年，雷云敏锐嗅到了网上购物的时代风口，果断推出综合网购平台“来云”，顺利搭上电商爆发的快车；承明历 67 年，顺应崛起的网购结算需求，雷云推出自研在线支付平台“RayPay（闪付）”，完成了商业闭环的最后一块拼图。
- **上市与集团化改制（68年）**：承明历 68 年，公司正式挂牌上市，主体更名为**“雷云集团股份有限公司”**，而原有的“雷云科技”则调整为雷云集团旗下的全资子公司，确立了现代化的集团控股治理架构。
- **理念分歧与万亿市值（72—75年）**：承明历 72 年，联合创始人李焕因公司管理理念与战略重心分歧，选择退出并离开雷云科技；其余四人继续稳步推进同城即时零售（来云闪购）与协同办公（飞鸽）业务。承明历 75 年，雷云集团总市值正式突破**一万亿元**大关。
- **人工智能布局与 Ripple 演进（77—80年）**：
  - **承明历 77 年**：雷云早早嗅到人工智能浪潮，全力投入底层算力与模型研发，于 77 年底正式推出 **Ripple 1.0 preview**，划分为三个参数档位（Density、Kelvin、Gravity）并宣布**全系彻底开源**，一举奠定了 Ripple 系列在开源中小模型领域称霸的基石。
  - **承明历 78 年**：年初推出 **Ripple 1.0 正式版**，凭借精妙的架构设计，以当时全球第二名仅一半的参数量短暂夺得全球 SOTA（最先进水平）；同年盛夏推出的 **Ripple 1.1** 再度复现了年初横扫榜单的盛况（也将当时刚成立、大打广告的皓月夜明早期 Duet 模型暴打）。
  - **承明历 80 年**：Ripple 系列一路迭代至 **Ripple 4.0**。然而此时旗舰模型 Density 的参数量虽已堆叠至惊人的 **2.4T（万亿）**，实际表现却显得平平无奇；反倒是中坚档位的 **Kelvin** 与轻量档位的 **Gravity**，自 1.0 时代起便一直是开发者与企业本地自部署模型的绝对首选，其中约 180B 参数规模的 Kelvin 等级模型，甚至能在诸多特定任务下凭借混合架构与高调优效率反超 Density。
- **功成身退（80年末）**：承明历 80 年末，已年近八十高龄的徐海正式卸任雷云集团董事长兼 CEO 职务，由联合创始人李云舟接班掌舵，自己则退居二线，安享晚年。

## 四、 雾城遇袭与静山医院的“赤狐重塑”（承明历82年初）

退居二线后的徐海并未完全停止社会活动。承明历 82 年初，受邀前往内陆工业大城**雾城**出席一场公开学术与商业讲座。

彼时，82 年初的一系列突发事件刚刚剧烈激化了洁癖派与跨越者群体之间的矛盾；而发源于星月湾的雷云集团自创立以来便一贯奉行对跨越者友好的雇佣与包容政策。尽管徐海本人只是纯碳基普通人类，且此次前往雾城根本没有携带任何跨越者随行，但他依然成为了极端洁癖派分子的泄愤目标。

讲座现场突发血腥袭击。尽管行凶的恐怖分子被当场抓捕，但年近八旬的徐海遭受了毁灭性的致命重创——**下半身被爆炸彻底炸烂，腹部更被利刃捅穿了一个大洞**。

徐海被紧急送往**雾城静山医院**抢救。由于伤势过重，他全靠体外循环设备与过量药物强行吊着最后一口气，维持大脑及残存脏器不至立刻坏死，医生判断他绝无可能撑过当晚。

### 1. 绝境摇人与云津起飞

远在星月湾的集团接班人李云舟获知噩耗后心急如焚，当即准备亲自带顶尖医疗团队赶赴雾城，却遭到重重阻挠。作为市值万亿、一举一动皆暴露在全社会聚光灯下的正道商业巨擘掌门人，李云舟无法动用越界手段去强行摆平这些阻挠。

就在受阻的同一瞬间，李云舟立刻想到了自己的女儿浅紫，以及她的伴侣茉璃。在浅紫与茉璃长久的相处中，李云舟深知那位看似安静娇小的猫娘拥有着跳出世俗舆论与规则束缚的绝对实力与随性心境，更兼备逆天的治愈能力。由茉璃与浅紫出马，不仅突破阻挠的成功率远超普通医疗队，甚至真有一线希望将徐海从鬼门关拉回来。

接到父亲电话的浅紫当即找上茉璃。既然是浅紫父亲的请求，茉璃爽快地答应帮忙。两人火速赶往约定的星月湾云津机场 96 号停机坪，登上了李云舟早已安排待命的私人公务机。为避免目标过大引发连锁政治风险，李云舟本人并未登机，但已向飞行员下达了死命令：**不惜一切代价将两位姑娘送到雾城静山医院附近，哪怕直接放弃飞机也在所不惜。**

### 2. 高架迫降与三角钉伏击

公务机呼啸着逼近雾城郊区。静山医院距离雾城机场极为遥远，加之机上几人早闻雾城地下猎杀组织“赫卡忒猎手”的恶名，无法确认此次袭击及后续阻挠是否与赫卡忒有关、更不确定航班行踪是否已被泄露。为了将夜长梦多的风险降至零，飞行员展现出了惊人的胆魄——直接驾驶公务机在距离静山医院不足 1500 米的一段**因施工封闭的高架桥面**上强行降落！

事实证明飞行员的果断救了所有人的时间。三人刚换乘车辆驶向医院，路面便出现了大量预先铺设的放气三角钉，车胎瞬间爆裂。

三人当即弃车狂奔。普通人出身的飞行员自然跟不上两位跨越者的速度，为了保命，他机敏地就近隐蔽躲藏，随后一路摸黑溜进了雾城公安局——在他看来，私自带跨越者入境外加违规降落高架桥，因为没有造成人员伤亡，顶多算是违反地方法规与航空管制，判个几年外加吊销执照便是上限；而李云舟为这趟任务许诺的高达八位数的巨额报酬，早已足够他后半生锦衣玉食、再不工作。可若是落进赫卡忒猎手手里，那才是真正的生不如死。

### 3. “治不好，但可以复活”

茉璃与浅紫一路疾驰抵达静山医院正门。此时医院外围已有内部人员接应，驻守在医院周边的雾城官方执法人员并未对两人过多阻拦——警察此行的任务本就是防范恐怖分子二次冲击医院；更何况徐海本人并非跨越者，也没带跨越者来雾城，仅因公司立场温和便遭此毒手，饶是平日里瞧不上跨越者的雾城本地警察，也觉得这帮极端分子干得太过火、太丢雾城的脸。

两人畅通无阻地冲进 ICU 病房。哪怕是杀过一些人的浅紫，在看到病床上只剩半截残躯、浑身插满粗大管线与电极片的徐海时，也不禁心惊肉跳。而若非医院听说有一位具备神妙治疗能力的跨越者正在赶来，单从人道主义出发，医生几乎已经准备让这位八旬老人体面安眠了。

茉璃上前一步，直接调动洋能为徐海止住了剧痛。原本处于深度弥留状态的徐海竟奇迹般地恢复了清醒，看着病床前的浅紫，满眼皆是难以置信——他没想到自己还能醒来，更没想到能在临死前见到云舟的女儿。

随后，茉璃在众医生心惊肉跳的注视下，一把扯掉了徐海身上维持生命的所有插管与电极片，以魔力维持徐海的生命，平静地抛下一句：

> “他这样是没法直接治好了喵。不过复活还是可以的。”

在场医生尽皆骇然懵圈。茉璃转头见浅紫早已不忍直视地躲到了角落，便干脆利落地将所有医护人员全部赶出病房，关上门开始重塑徐海的身体

她首先发动“生命窃取”，将徐海体内所有无法保留的坏死残破碳基组织清理干净，病床下只留下一滩消解后的黑水；紧接着，她以自身洋能为徐海从头捏造重塑新的躯体。

然而在捏人过程中，这只猫娘夹带了亿点点私货，茉璃先把 175cm 的身高直接缩水到一米六，再顺手去掉了原本的男性器官，换成了女性结构，最后在头顶加上一对毛茸茸的狐耳，身后加上一条蓬松的大尾巴，再把发色与毛色染成鲜亮的赤狐色……

两个小时后，病房大门重新打开。浅紫看着地板上静静昏迷着的赤狐娘少女陷入了长久的沉思，茉璃若无其事得地爬到浅紫身上。

当徐海再次睁开双眼时，看着自己白皙纤细的小手、以及身后毛茸茸的赤色大尾巴，整个人陷入了前所未有的懵逼。但转念一想：自己原本是个下半身被炸烂、必死无疑的八十岁老头，如今不仅捡回了一条命，白得了一身不弱的魔力底子，甚至还直接返老还童、恢复并超越了年轻时的巅峰体魄！相比于“再活一世”，变个性、长对狐狸耳朵尾巴又算得了什么？

想通之后的徐海对茉璃唯有无尽的感激。而茉璃也提前联系了李云舟，请他帮忙压下自己这项惊世骇俗的能力消息；李云舟自然满口答应，至于徐海为何大难不死后摇身一变成了年轻的赤狐娘跨越者，则由徐海本人出面杜撰了一套说辞对外搪塞了过去。

### 4. 雷云集团的铁腕反制与全面撤出（承明历82年初—83年中）

创世董事长在雾城遇刺险些丧命，彻底触碰了雷云集团的底线，也令集团高层开始全面审视洁癖派主导地区的安全隐患——事实上，诸如“来云闪购”的骑手在这些地区跑单存在人身风险的问题很早便已暴露，只是此前发生频次极少、一直未被上升到集团战略高度，直到徐海遇刺才真正引起了雷云管理层的高度警觉。

在徐海遇袭之后，雷云集团当即制定了铁腕撤离计划：**全面变卖并撤出位于洁癖派占政治主导权地区的所有雷云分部园区与机房设施**。这一庞大资产剥离与基础设施迁出工程历时一年有余，于**承明历 83 年中彻底完成**。

自此之后，雷云集团对上述洁癖派占政治主导权的地区实施了严厉的服务断供与降级管制：
- **全面停止 C 端增值与核心服务**：不再向这些地区提供包括**云服务器租赁**、**飞鸽**协同办公、**来云闪购**（彻底消除骑手遭遇极端分子袭击的风险）等在内的全部 C 端服务；
- **RayPay 与来云降级为“仅基础服务”**：
  - **RayPay（闪付）**：仅保留最基础的支付转账功能，其余金融、信贷（如闪电流水贷）、理财（如零钱宝）等服务全部中断；
  - **来云（网购）**：仅提供最基础的线上网购功能，并针对这些地区实施极其严苛的品类风控——**严格限制武器类商品与各类化学品的购买与流入**。

## 五、 玄砾电子与集团新纪元（承明历82年下旬—年末）

重获青春躯体与充沛精力的徐海，发现自己再也闲不住了——而更迫使这位八旬老帅重出江湖的，是雷云集团在底层算力硬件上面临的严峻政治与供应链危机。

### 1. 南溟洲芯片变天与算力卡脖子危机

彼时，全球绝大部分高端芯片企业均集中在**南溟洲**，而南溟洲中部及东部核心区的洁癖党与其他党派之间长期处于极其激烈的政治对抗中，导致全球高端芯片市场有一大半落入了洁癖派的掌控：
- 老牌处理器巨头**英泰尔**早在十余年前便已被南溟洲洁癖党资本控股；
- 更为致命的是，在**承明历 81 年中**，雷云“赤云”集群的核心计算卡供应商**阳伟达（Sunidia）**突发高层巨震——执掌公司三十余年的创始 CEO 被董事会以“不当私人关系及利益冲突独立调查”为由突袭，短短数日内便辞去总裁、CEO 及董事全部职务，哪怕内部上千名工程师联名请愿复职亦遭董事会强硬拒绝。外界与业内普遍认为，在南溟洲日益极化的政治绞杀下，这位没有 AB 股绝对控制权的创始人是嗅到了致命危险，故意借坡下驴、找了个私德理由“离职保命”以求全身而退；而在他卸任后，新上任的阳伟达 CEO 赫然是一名**南溟洲洁癖党党员**。

对于一贯对跨越者友好、且在徐海雾城遇袭后与洁癖派彻底撕破脸的雷云科技而言，底层算力芯片命脉攥在南溟洲洁癖党手里无疑是灭顶级别的风险。

### 2. 创立玄砾电子与“北斗七星”产品矩阵

承明历 82 年下旬，顶着赤狐娘少女外表的徐海正式宣布二次创业，结合自己早年在香橼计算机积累数十年的硬件工程底蕴，在雷云集团旗下创立半导体硬件子公司——**“玄砾电子”（ArcGravel）**，全面自研 **CPU、GPU 与 TPU** 等核心算力芯片。

（在规划业务范围时，徐海也曾考虑过是否将**存储芯片**纳入其中；但鉴于目前全球最大的存储芯片巨头——位于白虹城、占据全球 65% 存储芯片市场份额的**“三金存储”**由**望家掌握 72% 股份**，而另外两家存储芯片公司中一家位于北辰京、秉持中立态度，仅市场份额最小的一家受洁癖派控制，存储芯片供应链可确认无断供风险，徐海便放心地集中火力专攻算力逻辑芯片。）

徐海将玄砾电子的产品线以**北斗七星**命名，按面向的客户群体分为两类：
- **消费级产品线（以斗柄三星命名）**：消费级 CPU **玉衡（Alioth）**、消费级 GPU **开阳（Mizar）**、消费级 TPU **瑶光（Alkaid）**；
- **专业级、企业级产品线（以斗魁四星命名）**：服务器用 CPU **天枢（Dubhe）**、工作站 GPU **天璇（Merak）**、服务器 GPU/计算卡 **天玑（Phecda）**、企业级 TPU **天权（Megrez）**。

### 3. 四大元老各镇一方

承明历 82 年末，雷云集团迎来新一轮战略架构裂变：
- 联合创始人**王昌**挂帅创立“雷鸟科技”（Raiswift），主攻前沿的**具身智能（Embodied AI）**与机器人方向；
- 集团顶层治理结构同步完成重构：**李云舟**正式坐镇母公司，专职担任**雷云集团董事长**统揽全局；**浅云舒**则正式接掌全资核心子公司**雷云科技**；加上执掌**玄砾电子**的徐海与执掌**雷鸟科技**的王昌，四位创世元老在全新的黄金时代里各镇一方。
