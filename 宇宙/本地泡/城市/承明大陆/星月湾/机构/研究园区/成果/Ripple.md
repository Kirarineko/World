# Ripple大模型系列 · 混合推理架构

## 零、命名由来

三个模型层级均以波动现象命名，延续"Ripple"的波纹意象：

| 模型 | 取名来源 | 说明 |
| - | - | - |
| **Gravity** | 重力波 | 流体表面或内部由于重力作用而产生的波动，最基础的波现象之一。轻量模型，日常所见 |
| **Kelvin** | 开尔文-亥姆霍兹波 | 两种不同速度的流体交界处产生的不稳定波形。中坚模型，跨界融合 |
| **Density** | 密度波 | 介质密度差异驱动的深层振荡，能量最深沉。旗舰模型，深水区 |

### 开尔文-亥姆霍兹波（Kelvin-Helmholtz Wave）

这是两种不同速度的流体在交界面上产生的剪切不稳定性波形。

当快层流体掠过慢层流体表面时，界面因速度差而卷曲，形成规则排列的浪脊状涡旋，形如一排被风吹翻的海浪，在云层、木星大红斑边缘、土星环间隙乃至太阳日冕中均可观测到。

### 密度波理论（Density Wave Theory）

由林家翘与徐遐生于1964年提出，用以解释旋涡星系旋臂的持久结构。

旋臂并非固定的物质臂，是密度分布的波纹：恒星与气体在绕银心公转时穿越密度波，在波峰处因引力聚集而压缩、触发恒星形成，离开波峰后又散开。

旋臂因此是"交通堵塞"而非"旋转的臂"恒星不断流入流出，波纹本身保持稳定。银河的旋臂正是这样的密度波涟漪，在旋转中维持了数十亿年。

> **在这个世界观里，人类观察到的都是高斯泼溅形成的星空，但它投影出了位于其他泡的真实星空，即使泡之间并没有空间关系**

## 一、模型族

| 模型 | 参数规模 | 架构 | 定位 |
| - | - | - | - |
| **Ripple Density 2.0**（密度波） | 704B 总参数，21B 激活（MoE） | Sparse MoE，16专家/层，每Token激活2专家 | 旗舰。复杂推理、长文本生成、硬问题 |
| **Ripple Kelvin 2.0**（开尔文波） | 182B 总参数，10B 激活（MoE） | Sparse MoE，8专家/层，每Token激活2专家 | 中坚。日常对话、辅助写作、代码生成 |
| **Ripple Gravity 2.0**（重力波） | 27B，Dense | 全激活Dense | 轻量。边缘部署、高速响应、嵌入式场景 |


三者共享同一个 tokenizer（词表 256K）和 S200 推理引擎，差异仅在参数规模与 MoE 路由结构。Genius2 的刺激模式编码器（见第四节）对三个模型是同一套：它不关心模型多大，它只关心"S200 现在在想什么"。

> Genius2 的神经元不来自人类活体。皮层类器官从志愿者捐赠的皮肤成纤维细胞重编程而来。每个培养皿里的神经元在法律上属于"人类来源的体外组织"，不是"人脑"。这层边界被严格执行。

> HBI 在湿件领域领先全球至少一个代际。当国际同行还在用二维单层培养做概念验证时，HBI 研发的六层皮质类器官已由雷云科技投资实现工业化培养量产，并在其上运行推理任务。这个优势的根源很简单：星月湾有世界上唯一一个能把海洋科学、计算机科学和生命科技放在同一个课程表里的地方。湿件培养的微血管支架灵感来自海科的海藻多糖研究，刺激编码算法来自计科的非线性系统建模，培养方案本身是生科的主场：任何一个学科单干，都到不了这一步。


## 三、刺激模式编码

这是整个架构中唯一一处"跨物种翻译"：将人类语言的符号空间映射到神经元可感知的电刺激空间。

| 编码原则 | 说明 |
| - | - |
| 不编码语义 | Genius2 没有"词义"。刺激模式不携带语义信息。它携带的是 S200 对当前生成步骤的"困惑度"与"犹豫方向" |
| Beam 分歧编码 | 当 S200 的 top-3 beam 在某个 token 位置上严重分歧时，刺激模式为多电极异步脉冲：多个电极在不同频率上独立运行。Genius2 对此的响应波形在解码后通常表现为较大幅度的 Δ |
| Beam 收敛编码 | 当 top-3 beam 高度一致时，刺激为单电极或同步脉冲。此时的修正向量 Δ 幅值通常很小：S200 本来就有信心的地方，Genius2 不会"多嘴" |
| 上下文记忆 | 刺激模式携带了"距离开头多远"和"当前在回答中的位置"的信息，通过脉冲序列的总体时长编码。Genius2 对回答初期、中期、末期的刺激有不同的基线响应：它在"感觉到"一段对话的节奏 |


> 编码策略的设计原则是一句玩笑但也是实话："我们不告诉 Genius2 人类在说什么。我们只告诉 Genius2，S200 现在有多纠结。"


## 四、Genius2 到底做了什么

Genius2 不是第二个 AI。它是一个由活体神经元构成的、在持续接受 S200 的"情绪刺激"后给出生物电反馈的装置。

我们对它行为的已知事实：

| 已知 | 解释 |
| - | - |
| 修正向量方向在连续 Token 间具有弱相关 | 前一步的刺激影响神经元的突触后电位残余，这种残余持续约 2–3 步 |
| 不同培养阵列对同一刺激给出不同的 Δ | 个体差异。项目组内部给每个培养阵列起了名字："偏执狂"那个总在否定 S200，"和事佬"那个总是轻微加强 S200 的首选。推理时使用多阵列的均值 Δ，个别阵列的极端值被 τ-clip 削平 |
| 长时间运行后突触疲劳 | 高强度推理持续约 4 小时后，Δ 幅值降至初始的 60%。目前应对策略是每 2 小时插入 5 分钟的零刺激静息期。研究人员管这叫"让 Genius2 发呆"：静息期间不给任何刺激，让神经元回到自发基线放电状态 |
| 偶尔产生高幅值异常尖峰 | 神经元集群偶发同步放电，持续时间极短（\< 50 ms），强度巨大。对应的解码向量 Δ 在某个极小维度上有一个孤立的大分量（接近 ±0.03 的边界）。这些"尖峰修正"有时让输出多了一个出人意料的语气词，有时让一个关键动词从"建议"变成了"认为"。目前无人能解释这些尖峰的触发条件 |

## 七、Genius2 到底有没有用

这是一个项目组被问过无数次的问题。以下是经过上百组盲测对照的诚实回答（### 客观差异

- **创意写作**）在开放结尾叙事、诗歌生成、对话创作等场景，双盲评审员选 Density+Genius2 输出的比例约为 61%（vs 纯 S200 的 39%）。差异在 p\<0.01 水平显著。

- **多轮对话**：对话超过 15 轮时，Density+Genius2 在用户满意度上高出约 7 个百分点。主要差异在于避免重复句式：Genius2 似乎对"句式惯性"有微弱的抑制倾向。

- **事实准确性和数学**：无显著差异。Genius2 在需要精确推理的任务上不产生正向贡献，反而疑似会降低准确度。

### 主观体验

项目组内部有一个非正式共识：Genius2 给的东西与其说是"更好的答案"，不如说是"更有温度的偏差"。它不保证正确，不保证高效，不保证符合任何评估基准上的排名提升。它只保证一件事：当 S200 在两个几乎等概率的措辞之间犹豫时，Genius2 替它做了选择，而且这个选择来自一些活的神经元，不是来自另一层矩阵乘法和 softmax。
