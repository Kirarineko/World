它诞生于承明历59年。历经二十余载的激进裂变，雷云早已脱离了单纯“云服务商”的初级形态，建立起集底层算力基建（钢云/赤云/髓云）、国民级数字钱包与金融工具（RayPay / 闪付）、超级网购平台（来云）、同城半小时即时配送（来云闪购）、企业级协同办公系统（飞鸽）以及前沿通用人工智能（Ripple / Rainer）于一体的无缝商业生态闭环，并在承明历82年进一步战略裂变出全资半导体芯片公司“玄砾电子”与具身智能公司“雷鸟科技”。

## 发展史：从海湾机房到商业航母

### 1. 云服务起家（承明历57–64年）

承明历57年，首任董事长**徐海**经历了一场人生的戏剧性转折——他出生于明川，18岁赴北星洲北辰京读大学，毕业后在老牌个人电脑巨头“香橼计算机”任职数十年，主导过多款PC产品设计（产出过几代爆款，但也有大部分尝试石沉大海）。57年北星洲爆发金融危机，年近六旬的徐海在公司大裁员中遭到解雇。

回到承明大陆后，徐海着手准备创业。当时西北的望城刚刚起步，虽然普遍被外界看好，但经验老道的徐海经过权衡，最终还是选择了信息技术正在蓬勃发展、环境相对稳健保险的**星月湾**。

在星月湾，徐海结识了四个刚从昭明京承明大学毕业、意气风发的计算机高材生：年仅 23 岁的**李云舟**、24 岁的**浅云舒**，以及同窗好友**李焕**与**王昌**。经过一段时间的深入交流，五人一拍即合，于承明历59年（公开日同年）在星月湾合伙创立了**雷云科技**，以云服务为主业。

他们敏锐地抓住了大陆技术剧变引发的数字化浪潮，巧妙利用星月湾山体常年清冽的地下泉水作为自然冷却源，搭建了大陆第一批高性价比、低能耗的虚拟主机与分布式数据中心，并正式定名为**“钢云”**。

在那个绝大多数政企还在依靠纸质账册和老式局域网的年代，钢云凭借极其亲民的定价，迅速横扫了全大陆中小企业、科研院校和独立开发者的服务器托管市场，赚取了最初的数字资本。

### 2. 网购、支付与上市改制（承明历65–75年）

- **搭上网购风口（承明历65年）**：雷云敏锐嗅到了网上购物的时代风口，顺势孵化并推出综合网络购物平台**“来云”**，开放个人与中小商家入驻，顺利搭上了电商爆发的快车。
- **推出在线支付（承明历67年）**：借着迅速崛起的网上购物业务，为解决跨城交易信任壁垒与传统银行汇兑迟滞，雷云于67年正式推出了自己的在线支付平台——**RayPay（闪付）**，确立了“云 + 电商 + 支付”三位一体的增长飞轮。
- **挂牌上市与集团化架构（承明历68年）**：承明历68年，公司正式挂牌上市，母公司更名为**“雷云集团股份有限公司”**，原有的**“雷云科技”**则作为雷云集团旗下的全资子公司继续承载核心科技与云业务。
- **创始团队的理念分野（承明历72年）**：伴随着商业规模的爆发式膨胀，创始团队在公司治理与战略重心上出现了重大分歧。承明历72年，联合创始人**李焕**因管理理念不合选择退出并离开了雷云科技，五人创始团队缩减为四人（徐海、李云舟、浅云舒、王昌）。
- **本地生活、组织数字化与万亿市值（承明历72–75年）**：雷云将同城速递、餐饮生鲜整合为30分钟送达的**“来云闪购”**，并将内部千锤百炼的协同办公工具**“飞鸽”**推向全社会。承明历75年，雷云集团总市值正式突破**一万亿元**大关。

### 4. 智算纪元与 Ripple 大模型生态（承明历77年至今）

承明历77年，雷云早早嗅到了人工智能浪潮，全面启动全栈 AI 战略：

- **Ripple 1.0 preview 开源奠基（承明历77年底）**：77年底正式推出 **Ripple 1.0 preview**，划分为三个参数档位（Density、Kelvin、Gravity）并宣布全部开源，自此奠定了 Ripple 系列在开源中小模型领域称霸的基础；
- **Ripple 1.0 与 1.1 的 SOTA 盛况（承明历78年）**：78年初推出 **Ripple 1.0 正式版**，以当时第二名仅一半的参数量短暂达到全球 SOTA；同年盛夏推出的 **Ripple 1.1** 再度复现了年初的盛况；
- **赤云、髓云与 Ripple 4.0（承明历78–80年）**：由联合创始人浅云舒主导打造高性能异构算力平台“赤云”，并投资量产 HBI 提供的“髓云”（Genius2 活体神经元湿件计算）。至承明历80年，Ripple 系列已迭代至 **Ripple 4.0**：旗舰 **Density** 参数量高达 **2.4T（万亿）**，但表现平平无奇；反倒是中坚 **Kelvin** 与轻量 **Gravity** 自 1.0 推出以来一直是本地自部署模型的首选，约 180B 参数规模的 Kelvin 等级甚至能在特定任务下超越庞大的 Density；
- **智能编程工具**：基于 Ripple 打造了全大陆开发者标配的智能编程辅助工具 **Rainer**。

## 核心业务支柱

### 一、 云计算与智能算力平台（Raiun Cloud）

雷云科技的基石与动力之源，服务全球数百万政企与开发者：

- **钢云（通用计算）**：现代化的分布式虚拟化基础设施，涵盖弹性云服务器、高性能对象存储、托管分布式数据库、自动化负载均衡与微服务编排。
- **赤云（异构加速智算）**：大规模智能算力集群与托管平台。提供裸金属独占权限与云端 API 推理/训练即服务，承载着全大陆各大企业与科研院所的模型任务。
- **髓云（活体湿件计算即服务）**：星月湾最具辨识度的独门算力形态。以纯人源 3D 皮质类器官阵列（Genius2）为基底，由 HBI 提供核心技术、雷云投资实现工业级量产，神经元单段演化耗时仅 30–80 毫秒，功耗远低于纯硅基方案，为开放式创意生成、多轮深度对话与长上下文情感共鸣提供了全球最富温度的选项。

### 二、 数字支付与金融底层：RayPay（闪付）

作为全大陆数字支付的开创者与基础设施，RayPay（闪付）：

- **基本盘与绝对主流**：作为连接亿万用户与数百万商户的商业清算中枢，RayPay 牢牢统治着“来云”电商生态的核心交易盘、大额商品购买、对公企业转账、商户经营性流动资金授信（“闪电流水贷”）以及个人理财资产沉淀（“零钱宝”）。在重度商业交易、长途跨洋大宗物流调度以及大额资金往来上，其安全壁垒与专业金融属性无可撼动。
- **与社交支付的双寡头竞争**：
  - 近年来，另一款依托国民级个人即时社交平台的支付工具横空出世，凭借极高频的日常社交聊天入口、熟人转账、社交红包以及近乎零门槛的离线扫码，在街头早餐摊、出租车、便利店小额买单及朋友 AA 等日常生活高频场景中迅猛渗透，抢走了极大的日常风头与街头曝光度；
  - 这种竞争态势高度类似于现实中的“支付宝与微信支付”：对手凭借社交高频优势在小额碎片场景大行其道，而 RayPay（闪付）则凭借深厚的商业信誉、完善的信贷理财体系与大宗商贸底座，依然稳坐数字商业主流半壁江山，两者共同维系着全大陆数字支付的双寡头格局。
- **洲际内循环清算（无跨国贸易）**：由于本世界观下四大洲统一归属于同一个主权国家（联合国框架），全大陆通用法定货币，因此不存在“跨国贸易”或“跨币种汇兑”。RayPay 承担的是跨承明、离火、南溟、北星四大洲之间长达万里的大洋航运商贸、大宗物资跨洲调配与省市各级银行业务的实时资金流转。

### 三、 综合数字商业平台：来云（Laiyun）

连接千万商家与亿万消费者的超级数字市集：

- **全品类生态**：服装配饰、数码硬件、生活日化、原产地海鲜果蔬、图书文创乃至工业原材料无所不包。
- **商业基础设施**：提供完善的商家后台管理系统、千人千面的智能推荐算法、买家信誉与店铺信用评级体系。
- **大促狂欢**：每年固定举办的大促活动，每秒并发交易峰值数以百万计，成为考验雷云钢云与 RayPay 架构极限的“数字压力大考”。

### 四、 本地生活与即时零售：来云闪购

近期全面融合入“来云”主应用的核心板块，大陆即时物流与近场电商的代名词：

- **业务范围**：主打 30 分钟同城外卖、连锁生鲜商超冷链直达、夜间医药应急配送与点对点帮送跑腿。
- **庞大骑手网络**：由智能调度算法指挥的蓝黄色骑手车队穿梭在各大城市的日夜中，不仅重塑了普通市民的用餐与消费习惯，更提供了数以百万计的灵活就业岗位。

### 五、 企业协同办公平台：飞鸽（Feige）

源于雷云内部极致工程师文化与组织敏捷诉求的高效办公套件：

- **产品架构**：以“沟通即协作”为理念，将即时聊天、日历日程、多人在线实时协同文档、音视频云会议、多维智能数据表、项目看板与人事审批流深度啮合为一体。
- **社会普及度**：飞鸽彻底终结了繁琐的纸质报销与邮件拉扯时代。望城的 AI 极客团队、海渊城的航海调度室、星月湾的科技企业，乃至昭明京联合国办事处的大量工作组，日常工作全部运转在飞鸽之上。

### 六、 前沿大模型与开发者生态：Ripple 矩阵

- **Ripple 基座大模型**：
  - **三级族谱与演进（1.0 preview → 4.0）**：以波动现象命名——轻量级 **Gravity** 面向边缘与本地部署，中坚 **Kelvin**（约 180B 级 MoE）面向日常对话、代码生成与高性价比自部署，旗舰 **Density**（至 4.0 版本参数量已达 2.4T）面向超大规模探索。自 77 年底 1.0 preview 推出以来，Kelvin 与 Gravity 凭借极佳的能效比统治了开源中小模型与自部署市场，Kelvin 甚至常在特定任务中反超参数庞大的 Density；
  - **S200 + Genius2 混合推理**：Density 与 Kelvin 支持运行在赤云集群的 S200 加速卡与髓云 Genius2 湿件神经网络的混合架构上，亦可切换纯硅基旁路；Gravity 为纯硅基。模型规格与演进细节见本目录 `Ripple.md`；
  - **全模态融合**：涵盖自然语言理解、高难度代码逻辑、数学物理推理、多模态视觉理解（图表/高分辨率照片/视频分析）及长文本深度上下文；
  - **开源与云端双轮驱动**：Ripple 秉持极其彻底的开源路线，其权重全网开源，成为开源社区首选的基座底模；同时在赤云 API 平台上提供经过强化对齐的企业级商业接口，全大陆数千家 AI 创业公司的产品均生长在 Ripple 的生态土壤之上。
- **Rainer**：
  - 基于 Ripple 代码理解与生成能力深度打磨的专业编程助手；
  - 提供极低延迟的行内续写、复杂重构、单元测试生成与终端 Shell 交互，是全大陆开发者的必备生产力工具。

### 七、 承明历82–83年战略裂变与洁癖派主导区撤出

在后续时间线（承明历82年至83年）中，雷云集团一方面向底层硅基芯片与物理具身智能延伸，另一方面在创世董事长徐海遇袭后对洁癖派主导地区实施了彻底的资产剥离与服务断供：
- **玄砾电子（承明历82年下旬创立）**：由于全球高端芯片企业大多集中于党派冲突激烈的南溟洲，且过半高端芯片市场掌握在洁癖派手中（如英泰尔十余年前即被南溟洲洁癖党控股，阳伟达原CEO于81年中找理由“离职保命”卸任后亦换上了洁癖党党员担任新CEO），对雷云科技构成严重供应链风险。为此，在雾城遇袭后经茉璃以洋能重塑为年轻赤狐娘少女的创世董事长**徐海**于82年下旬二次创业掌舵玄砾电子，推出以**北斗七星**命名的消费级（斗柄三星：玉衡CPU、开阳GPU、瑶光TPU）与专业/企业级（斗魁四星：天枢服务器CPU、天璇工作站GPU、天玑服务器GPU计算卡、天权企业级TPU）自研芯片产品线，致力于彻底打破外部硬件掣肘（详见本目录 `玄砾电子.md`）。
- **雷鸟科技（承明历82年末创立）**：由联合创始人**王昌**挂帅掌舵，主攻前沿**具身智能（Embodied AI）**与智能机器人研发。
- **洁癖派主导地区的全面撤资与服务降级（承明历82年初规划—83年中完成）**：
  - **园区与机房彻底清空**：承明历82年初徐海在雾城遇袭后，雷云集团立即计划卖掉位于**洁癖派占政治主导权地区的所有分部园区与机房**，并于**承明历83年中彻底完成**资产出售与撤离。
  - **C端服务全面停供**：自撤出完成后，雷云集团不再向这些地区提供C端服务，包括**云服务器租赁**、**飞鸽**、**来云闪购**（骑手在这些地区面临安全风险的问题其实很早就已暴露，但因过去发生极少而未被重视，直到徐海遇刺才真正被集团关注到）等。
  - **RayPay 与来云仅保留基础功能并严控违禁品**：**RayPay（闪付）**对这些地区仅保留基础支付功能，其余信贷、理财等衍生金融服务全部中断；**来云**仅对这些地区提供最基础的网购服务，并**严格限制这些地区对武器类商品及各类化学品的购买**。

## 园区格局与空间过载危机

随着雷云科技从一家初创云厂商膨胀为员工超十万、业务横跨六大领域的庞然大物，其发源地星月湾与中枢昭明京之间，形成了极其鲜明的空间张力。

### 星月湾老园区：月心深处的“严重过载”

- **占地规模**：占地约 12 万平方米（0.12 平方公里）。
- **空间位置**：坐落于星月湾月心区后缘，紧邻南湾与丘麓交界处的山体坡地。
- **设计初衷与现实反差**：
  - 这座十余年前建成的现代园区最初规划仅容纳 3000 至 4000 名核心研发人员；
  - 伴随着来云、RayPay、飞鸽等各大业务线火箭般的扩张，如今这座老园区里强行挤入了**超过 12,000 名正式员工**，过载率超过 300%。
- **过载日常生态**：
  - **工位极限压缩**：原有的休息茶水间、景观连廊甚至部分室内露台全被改造成了密密麻麻的开放式工位；
  - **会议室战争**：飞鸽上的会议室预定排期堪比春运抢票，半夜十二点放出一周后的会议室瞬间被秒光；许多小组讨论被迫移步园区草坪、走廊过道或南栈后街的咖啡馆；
  - **食堂狂澜**：三座员工食堂在午间高峰期排出的队伍如贪吃蛇般蜿蜒穿过办公楼前广场，员工自嘲“在食堂排队打一份烤鱼饭的时间，足够云端跑完一次中型模型微调”；
  - **周边挤占**：上万名高薪技术人员与运营涌入，直接将南湾住宅区与樱巷周边的租金推高了数倍，清晨与傍晚的共享单车与私家车彻底堵死了原本宁静的南湾小道。
- **未来战略转型**：星月湾老园区已无任何物理扩建空间。在昭明京新园区全面封顶交付后，星月湾园区将逐步剥离庞杂的商业运营、电商销售、法务与一般金融团队，回缩定位于**“集团发源地与硬核科研中心”**，专精于前沿算法实验室、湿件计算（髓云）基地与尖端算力基建。

### 昭明京新总部园区（在建）：近郊的超级科技小镇

为彻底化解星月湾老园区的空间窒息，并深度拥抱大陆政治、金融与国际规则的核心，雷云科技于承明历76年启动昭明京新全球总部建设：

- **占地规模**：整整 **108 万平方米（约 1.08 平方公里）**，是星月湾老园区的整整九倍之巨。
- **地理选址**：昭明京近郊，长宁与承天两大国际机场之间的高新交通走廊。
- **战略定位**：规划容纳 **50,000 至 80,000 名员工**，定位为雷云科技集团的**全球综合超级总部**，承载集团董事局、来云电商全域运营、RayPay 数字金融、飞鸽交付中心与各大洲业务中枢。
- （详见：`承明大陆/昭明京/机构/雷云科技昭明京园区（在建）.md`）

## 领导层与权力接棒

雷云集团在承明历 80 年至 82 年间完成了意义深远的权力交接与顶层架构演进：

- **首任董事长徐海（年近80岁）卸任与传奇新生**：
  徐海生于明川，18岁赴北星洲北辰京读大学并任职于“香橼计算机”，承明历57年因北星洲金融危机被裁员后回到承明大陆，于59年在星月湾与四位年轻人创办雷云。他担任董事长兼 CEO 直至**承明历 80 年末**，在年近八十高龄时正式退居二线，由李云舟接班。
  （注：在后续的承明历 82 年初，徐海在雾城讲座中遭极端洁癖派袭击垂危，经浅紫与茉璃驰援静山医院并以洋能重塑肉身，变成身高 160cm 的年轻赤狐娘少女，随后于 82 年下旬再次出山创立集团旗下的芯片公司**玄砾电子**。详见 `角色/星月湾/徐海/`。）

- **李云舟（45岁）接掌雷云集团**：
  联合创始人**李云舟**在集团内部拥有崇高的战略威望，主导了来云电商、RayPay 支付体系以及昭明京超级新总部园区的规划落地。他在承明历 80 年末正式接班徐海，并在承明历 82 年末的集团结构变更中专职坐镇母公司，担任**雷云集团董事长**。

- **浅云舒（46岁）从总架构师到执掌雷云科技**：
  作为联合创始人与李云舟的妻子，**浅云舒**自创业之初起便专注于软硬件底层架构与前沿智算攻关（主导“赤云”等核心工程）。在承明历 82 年末集团组织架构变更后，随着李云舟专职担任雷云集团董事长，浅云舒正式出任全资核心子公司**雷云科技**的掌舵人。

- **王昌的共识与执掌雷鸟科技**：
  作为留任至今的联合创始人，**王昌**在集团权力交接过程中与李云舟等深入磨合达成全员共识，全力支持李云舟接棒集团大盘；并在承明历 82 年末挂帅创立集团旗下的**雷鸟科技**，主攻具身智能赛道。

## 企业文化与社会影响

- **企业愿景**：“让数字在云端流淌，让生活在指尖闪亮。”
- **大厂与小城之融**：在星月湾，雷云科技既是一座令人仰望又有些无奈的“巨兽”——它带来了巨额的市政税收与年轻活力，却也带来了小城原本未曾有过的快节奏加班、深夜外卖与租金焦虑。
- **商业与法治共处**：作为跨越者友好的巨头，雷云科技在招聘中严格奉行不歧视跨越者的原则，开发了多种适配非人形态员工的无障碍办公硬件与工位系统；而在昭明京，雷云法务与公共事务团队则深耕于联合国各项数据标准的制定研讨。承明历82年初徐海在雾城遇刺后，集团更以强硬姿态于83年中彻底售出并撤离洁癖派占政治主导权地区的全部园区与机房，全面停供当地C端云租赁、飞鸽与来云闪购，并对RayPay与来云实施功能熔断与武器、化学品禁售管制。
