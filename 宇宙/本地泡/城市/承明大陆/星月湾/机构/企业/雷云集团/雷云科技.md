雷云科技是雷云集团（Raiun Group）旗下体量最大、业务最核心的全资子公司。它不仅是雷云从海湾小机房起步的业务原点，更承载着集团面向整个承明大陆乃至四大洲的数字化与智能化基础底盘。

在承明历82年末的集团治理架构升级中，随着李云舟专职坐镇母公司担任雷云集团董事长，联合创始人兼总架构师**浅云舒**正式出任雷云科技总裁，全面统揽云计算底座、前沿算法实验室、湿件计算（髓云）与数字生活软件生态。

## 核心业务支柱

### 一、 云计算与智能算力平台（Raiun Cloud）

雷云科技的基石与动力之源，服务全球数百万政企与开发者：

- **钢云（通用计算）**：现代化的分布式虚拟化基础设施，涵盖弹性云服务器、高性能对象存储、托管分布式数据库、自动化负载均衡与微服务编排。早期巧妙利用星月湾山体地下泉水自然冷却，树立了极高能效标杆。承明历83年秋起，兄弟公司玄砾电子自研的“天枢（Dubhe）7751 / 7551”服务器CPU量产上线钢云，凭借自供优势与极低利润率策略，同规格性能的服务器租用价格比英泰尔机型低近60%；总裁浅云舒更立下五年内将RayPay、来云等全部核心服务底层全面迁移至Dubhe架构的目标。
- **赤云（异构加速智算）**：大规模智能算力集群与托管平台。提供裸金属独占权限与云端 API 推理/训练即服务，承载着全大陆各大企业与科研院所的模型任务。
- **髓云（活体湿件计算即服务）**：星月湾最具辨识度的独门算力形态。以纯人源 3D 皮质类器官阵列（Genius2）为基底，由 HBI 提供核心技术、雷云投资实现工业级量产，神经元单段演化耗时仅 30–80 毫秒，功耗远低于纯硅基方案，为开放式创意生成、多轮深度对话与长上下文情感共鸣提供了全球最富温度的选项。

### 二、 数字支付与金融底层：RayPay（闪付）

作为全大陆数字支付的开创者与基础设施，RayPay（闪付）：

- **基本盘与绝对主流**：作为连接亿万用户与数百万商户的商业清算中枢，RayPay 牢牢统治着“来云”电商生态的核心交易盘、大额商品购买、对公企业转账、商户经营性流动资金授信（“闪电流水贷”）以及个人理财资产沉淀（“零钱宝”）。在重度商业交易、长途跨洋大宗物流调度以及大额资金往来上，其安全壁垒与专业金融属性无可撼动。
- **与社交支付的双寡头竞争**：
  - 近年来，另一款依托国民级个人即时社交平台的支付工具横空出世，凭借极高频的日常社交聊天入口、熟人转账、社交红包以及近乎零门槛的离线扫码，在街头早餐摊、出租车、便利店小额买单及朋友 AA 等日常生活高频场景中迅猛渗透；
  - 这种竞争态势高度类似于现实中的“支付宝与微信支付”：对手凭借社交高频优势在小额碎片场景大行其道，而 RayPay（闪付）则凭借深厚的商业信誉、完善的信贷理财体系与大宗商贸底座，依然稳坐数字商业主流半壁江山，两者共同维系着全大陆数字支付的双寡头格局。
- **洲际内循环清算（无跨国贸易）**：由于本世界观下四大洲统一归属于同一个主权国家（联合国框架），全大陆通用法定货币，因此不存在“跨国贸易”或“跨币种汇兑”。RayPay 承担的是跨承明、离火、南溟、北星四大洲之间长达万里的大洋航运商贸、大宗物资跨洲调配与省市各级银行业务的实时资金流转。

### 三、 综合数字商业平台：来云（Laiyun）

连接千万商家与亿万消费者的超级数字市集：

- **全品类生态**：服装配饰、数码硬件、生活日化、原产地海鲜果蔬、图书文创乃至工业原材料无所不包。
- **商业基础设施**：提供完善的商家后台管理系统、千人千面的智能推荐算法、买家信誉与店铺信用评级体系。
- **大促狂欢**：每年固定举办的大促活动，每秒并发交易峰值数以百万计，成为考验雷云钢云与 RayPay 架构极限的“数字压力大考”。

### 四、 本地生活与即时零售：来云闪购

全面融合入“来云”主应用的核心板块，大陆即时物流与近场电商的代名词：

- **业务范围**：主打 30 分钟同城外卖、连锁生鲜商超冷链直达、夜间医药应急配送与点对点帮送跑腿。
- **庞大骑手网络**：由智能调度算法指挥的蓝黄色骑手车队穿梭在各大城市的日夜中，不仅重塑了普通市民的用餐与消费习惯，更提供了数以百万计的灵活就业岗位。

### 五、 企业协同办公平台：飞鸽（Feige）

源于雷云内部极致工程师文化与组织敏捷诉求的高效办公套件：

- **产品架构**：以“沟通即协作”为理念，将即时聊天、日历日程、多人在线实时协同文档、音视频云会议、多维智能数据表、项目看板与人事审批流深度啮合为一体。
- **社会普及度**：飞鸽彻底终结了繁琐的纸质报销与邮件拉扯时代。望城的 AI 极客团队、海渊城的航海调度室、星月湾的科技企业，乃至昭明京联合国办事处的大量工作组，日常工作全部运转在飞鸽之上。

### 六、 前沿大模型与开发者生态：Ripple 矩阵

雷云科技是承明大陆通用人工智能与大模型工业化的领头羊：

- **Ripple 基座大模型**：
  - **三级族谱与演进（1.0 preview → 4.0）**：以波动现象命名——轻量级 **Gravity** 面向边缘与本地部署，中坚 **Kelvin**（约 180B 级 MoE）面向日常对话、代码生成与高性价比自部署，旗舰 **Density**（至 4.0 版本参数量已达 2.4T）面向超大规模探索。自 77 年底 1.0 preview 推出以来，Kelvin 与 Gravity 凭借极佳的能效比统治了开源中小模型与自部署市场，Kelvin 甚至常在特定任务中反超参数庞大的 Density；
  - **S200 + Genius2 混合推理**：Density 与 Kelvin 支持运行在赤云集群的 S200 加速卡与髓云 Genius2 湿件神经网络的混合架构上，亦可切换纯硅基旁路；Gravity 为纯硅基。模型规格与演进细节见本目录 `Ripple.md`；
  - **开源与云端双轮驱动**：Ripple 秉持极其彻底的开源路线，其权重全网开源，成为开源社区首选的基座底模；同时在赤云 API 平台上提供经过强化对齐的企业级商业接口，全大陆数千家 AI 创业公司的产品均生长在 Ripple 的生态土壤之上。
- **Rainer**：
  - 基于 Ripple 代码理解与生成能力深度打磨的专业编程助手；
  - 提供极低延迟的行内续写、复杂重构、单元测试生成与终端 Shell 交互，是全大陆开发者的必备生产力工具。

## 掌舵人与研发文化

- **掌舵人浅云舒**：雷云五位创始人之一，李云舟的妻子，浅紫的母亲。她技术功底深厚扎实，自创业之初便负责总架构，主导打造了从早期的“钢云”到如今的“赤云”算力集群。她不喜夸夸其谈的商业应酬，常年深耕技术研发一线，是雷云工程师团队的技术图腾。承明历81年初，在女儿浅紫与茉璃处亲眼验证“GPU推理可实质干涉周围环境魔力”的发现后，浅云舒鉴于环境魔力呈加速上涨趋势、恶意用户未来可能通过特定提示词扰动机房魔力造成硬件破坏，第一时间赴昭明京与集团各大数据中心推动部署了机房魔力安全防护措施（详见 [`研究/GPU与魔力的干涉/`](../../../../../../研究/GPU与魔力的干涉/总览.md)）。
- **无障碍与多元包容**：作为发源于星月湾的科技领航者，雷云科技在工作环境中倡导高度平等的极客文化，开发了多款适配非人形态员工的无障碍办公硬件与工位设备，是跨越者求职者的理想殿堂。
- **洁癖派主导区的机房撤离与服务熔断（承明历82年初—83年中）**：在承明历82年初创世董事长徐海于雾城遇袭后，雷云启动了对洁癖派占政治主导权地区的全面撤出计划，于**83年中彻底卖掉并清空位于这些地区的所有分部园区和机房**。此后，雷云科技不再向这些地区提供C端服务——包括**云服务器租赁**、**飞鸽**、**来云闪购**（骑手在这些地区跑单存在人身安全风险的问题其实很早就暴露过，但此前发生极少而未受重视，直到徐海遇刺才引起集团警觉）等均全面停供；**RayPay（闪付）**与**来云**则对这些地区仅提供基础服务（RayPay仅保留基础支付功能、其余金融服务全部中断；来云仅提供基础网购，且**严格限制这些地区对武器类商品、化学品的购买**）。
