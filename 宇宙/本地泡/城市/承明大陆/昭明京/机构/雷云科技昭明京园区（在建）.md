# 雷云科技昭明京园区（在建）

> 占地 108 万平方米的近郊超级科技小镇。雷云帝国走向大陆中枢的标志性地标，亦是化解星月湾老园区窒息过载的破局之钥。

---

| 战略定位 | 全球综合超级总部（行政、金融、电商、即时生活、政企协同） |

## 建设背景：双重驱动下的破局

### 1. 星月湾老园区的空间窒息

雷云科技发源于星月湾，其现有的月心区老总部占地仅约 12 万平方米。伴随电商、支付、外卖即时零售与协同办公等业务的裂变爆发，老园区实际办公人数从规划的 3500 人一路飙升至 12,000 余人。

由于星月湾严控容积率与天际线，且周边被居住区与自然山体环抱，园区已无任何外延扩建可能。会议室抢破头、工位逼仄、食堂严重拥挤、周边交通与租金不堪重负。老园区的物理极限，成为制约集团下一阶段发展的最大硬伤。

### 2. 拥抱大陆权力与经济中枢

作为承明大陆的首都与联合国总部所在地，昭明京汇聚了全大陆最密集的金融机构总部、行业标准制定组织、各大洲商贸联络机构与顶尖高校。雷云科技旗下的 RayPay（支付金融）、来云（电商商业）、飞鸽（企事业协同）等核心业务，急需近距离与央行金融监管、大宗洲际物资调配协调机制以及庞大的政企客户群深度联动。在昭明京设立超级总部，是商业帝国发展的必然抉择。

## 规划理念与空间布局

园区没有采用传统的密集单一写字楼模式，而是借鉴了“超级科技小镇”理念，强调低密度、生态化与复合功能：

```
                    ┌────────────────────────┐
                    │    北区：云上生活小镇   │
                    │ (人才公寓/体育馆/配套) │
                    └───────────┬────────────┘
                                │
   ┌────────────────────┐       │       ┌────────────────────┐
   │ 西区：金融与结算岛 │       │       │ 东区：协同与政企岛 │
   │   (RayPay / 闪付)  │       │       │    (飞鸽交付中心)   │
   └─────────┬──────────┘       │       └──────────┬─────────┘
             │                  │                  │
             │     ┌────────────┴────────────┐     │
             └────►│   中枢：天圆地方总部大厦群  │◄────┘
                   │  (董事局/行政大脑/展厅) │
                   └────────────┬────────────┘
                                │
             ┌──────────────────┴──────────────────┐
             │       南区：数字商业与即时零售岛      │
             │      (来云电商 / 来云闪购大脑)      │
             └─────────────────────────────────────┘
```

### 一、 中枢核心：天圆地方总部大厦群

- 位于园区地理正中央，由五栋高低错落的现代塔楼组成，最高主楼设计高度 180 米，在昭明京近郊形成极具辨识度的新地标。
- 承载集团董事局办公室、全球战略投资部、人力资源中枢、法务与合规部、以及面向国际访客与政府代表的“数字文明未来体验馆”。

### 二、 南区：数字商业与即时零售岛

- 占地约 25 万平方米，为来云电商与来云闪购的全球运营总部。
- 容纳万名以上的类目运营、商家服务、用户体验保障团队以及来云闪购的智能即时调度指挥大厅。大厅内设有跨度达百米的巨幅数字孪生穹顶，实时跳动着四大洲数万个街区的即时外卖与零售配送热力图。

### 三、 西区：金融与科技结算岛

- RayPay（闪付）的核心中枢。
- 配备极高防护标准的地下金融算力节点与多重冗余电网，承担全大陆跨行资金汇兑、跨洋大宗商贸清算、商户流动资金借贷风控及数字安全攻防实验室。

### 四、 东区：协同与政企岛

- 飞鸽软件的全球研发与交付基地。
- 紧密对接昭明京的各级企事业单位与联合国直属各专门机构，常年设有政企数字化转型开放工作坊与培训中心。

### 五、 中央水系与“星月湖”

- 为延续集团在星月湾的发源地情感，园区中心开挖了一处占地约 15 万平方米的人工湖，命名为“星月湖”。
- 环湖分布着低密度的研发小独栋、咖啡馆、茶室与滨水步道。每当入夜，湖岸仿照星月湾灯火点亮微光，成为繁忙大厂节奏中的静谧绿洲。

### 六、 北区：云上生活小镇

- 专为青年技术与运营骨干打造的大型生活配套社区。
- 规划建设逾万套精装青年人才公寓、自营职工食堂群、大型综合室内体育馆、国际双语幼儿园、24小时智慧便民诊所与全自动无人物流超市。

## 交通与区位优势

园区选址昭明京近郊的核心考量之一便是极致的枢纽连通性：

- **双机场辐射**：距离昭明长宁国际机场仅约 15 公里，距昭明承天国际机场约 25 公里，高管与商务团队可实现“两小时覆盖承明大陆主要城市、当日通达四大洲主要枢纽”；
- **轨道交通**：昭明京地铁快线已规划专用站点“雷云园区站”，直达古都中心与昭明中站（高铁枢纽）；
- **专用路网**：园区外围紧邻高速环线出口，并预留了大型来云闪购自动驾驶配送与物流无人机起降坪。

## 现状与社会影响

### 建设现状

截至承明历81年秋，昭明京园区土建工程已完成大半：
- 中枢总部大厦群主体结构已全面封顶，正进行双层呼吸式玻璃幕墙安装；
- 星月湖水系及周边绿化已完成初步蓄水；
- 首批人才公寓与南区商业办公楼预计将于承明历82年末率先试运营。

### 集团内部反响与“北迁”讨论

昭明京园区的建设在雷云内部引发了深远讨论：
- 星月湾老园区内，飞鸽的各个内部大群与“飞鸽圈子”里，关于“哪些业务线整体北迁昭明京”、“两地薪酬与住房补贴差异”的讨论长盛不衰；
- 按照集团规划，来云电商、RayPay 金融与飞鸽的绝大多数运营、法务、商务团队将首批分流迁入昭明京；
- 而基石算力（钢云底层架构、赤云与髓云前沿实验室）、Rain 大模型核心团队则继续坚守星月湾老园区。一座年轻浪漫的海湾科技圣地，与一座宏大庄严的首都商业帝国，正在雷云科技的版图上完成历史性的分工与交接。
