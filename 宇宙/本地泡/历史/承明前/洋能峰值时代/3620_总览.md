# 洋能峰值时代

> 那二百四十年，天与地之间的距离比现在近得多。今人称之为神话。当事人不知道自己活在神话里。就像后羿射日、女娲补天、山海经里的奇禽异兽。没有人把这些传说当真。

## 概述

承明前约3620年，本泡的洋能渗透率出现了一次剧烈的异常峰值。

峰值发生时，人类已初步走出原始状态，封建体系与文字刚刚兴起。但洋能的剧烈涌入即刻摧毁了这套刚刚成形的社会结构：全球约九成人口在一个月内发生沉渊，社会崩解，文字也在第一场浩劫中失传。文明在这一刻倒退回近乎原始的状态。

峰值持续了约二百四十年。

在这二百四十年中，洋能浓度远超当代水平。大量超自然现象涌现：亚空间物质穿越维度界面进入泡内，人类中出现了能够驾驭洋能的个体，地理与气候在洋能场的影响下发生局部畸变。

峰值结束后，洋能浓度开始了长达四百年的缓慢衰退，期间有波动。天选者逐渐成为硕果仅存的"神明"，失去一切旧秩序的人类依附他们生存，围绕这些"神明"建立了新的社会制度——一种近似神权文明的形态。那些曾经可以驾驭洋能的人逐渐失去了力量，那些穿越而来的亚空间物质要么消散、要么退化、要么以残缺的形态留存于传说中。二百四十年的"奇迹"在随后的数千年中被口述、被神化、被改写，最终变成了今人所知的神话与传说。

**人类完全不知道当时存在洋能。**

没有人知道峰值为何发生。也没有人知道它为何结束。

这些传说从未被当真。后羿射日、女娲补天、山海经——它们是"古人的想象"，是"文化符号"，是"不能用科学解释的上古记忆"。没有人认为它们是真实发生过的事。

## 成因：亚空间堰塞湖决堤

### 机制

1. **复用区**：亚空间中存在一片较大的复用区，与本地泡共享物理坐标。这片复用区指向本地泡的地球

2. **隐蔽裂隙**：复用区附近已经存在大量裂隙。但这些裂隙大部分在深山深海中，有的甚至被压在山体下，当时人类**无法发现**，完全没有记录

3. **堰塞湖**：复用区附近存在一个巨大的"堰塞湖"。亚空间介质在这里大量聚集，形成了高密度的洋能富集区

4. **决堤**：堰塞湖决堤了。大量富含洋能的水通过那些隐蔽的裂隙冲入本地泡的地球

### 洋能释放

亚空间的一切物质都含有大量洋能，因为亚空间的"空气"就是洋能。堰塞湖里的就是水，亚空间的水。

当这些水冲入本地泡后，由于泡内环境洋能水平极低，亚空间介质开始**疯狂释放洋能**。

就像一块烧红的铁掉进冷水里：铁会把热量传给水，直到温度平衡。亚空间的水掉进泡内：水会把洋能传给环境，直到浓度平衡。

但堰塞湖的水量太大了。释放的洋能远远超过了泡内环境的正常水平。整个泡内的洋能浓度飙升，持续了约二百四十年，堰塞湖的水才逐渐释放殆尽，洋能浓度开始了长达四百年的缓慢衰退。

### 时间线

| 阶段 | 说明 |
| - | - |
| 决堤前 | 泡内洋能浓度**远低于现代**。裂隙存在但隐蔽，无人发现。封建体系与文字刚兴起 |
| 决堤瞬间 | 大量亚空间介质通过隐蔽裂隙涌入泡内。可能伴随地震、海啸、气候异变。封建体系崩解，文字失传，文明倒退回近原始状态 |
| 峰值期（240年） | 亚空间介质持续释放洋能，泡内浓度极高。超自然现象涌现，"英雄"与"妖怪"同时出现；人类围绕天选者形成宗教文明 |
| 衰退期（400年） | 堰塞湖的水释放殆尽，洋能浓度缓慢回落，期间有波动。"英雄"逐渐失去能力，"妖怪"逐渐消亡。约400年后（约前2980）人类族群规模基本恢复，社会自原始状态转入奴隶制 |
| 峰值后 | 洋能浓度回落，但仍高于决堤前。此后缓慢上升，至现代仍处于不均匀的上升趋势中 |

## 地理位置与传说版图

在峰值时代留存的传说框架中，整个已知世界被划分为三个层次：**人类聚居的凡俗之地**、**横亘大地的仙山天堑**，以及**海那头的"天外"**。

### 1. 凡俗聚居地与两脉文明

峰值发生前，人类主要分布在承明大陆的**西南部**，**西北部**也有少量族群定居。

峰值降临后，星银山脉一带的洋能浓度飙升至极值，伴随地貌畸变与大量变异生物、沉渊怪物的盘踞，整条山脉化作了凡人绝难逾越的死亡天堑。西南与西北两地的人类由此被彻底隔绝，各自围绕庇护当地的天选者，演化出了两套独立的神权文明。

在长达数百年的隔绝期里，普通人终生无法跨越山脉，两地之间唯一的联系，只有少数会横穿星银山脉并同时往来于山脉两侧的天选者。他们将一侧的器物、话语与见闻带往另一侧。

因此，西南与西北流传下来的上古传说呈现出一种微妙的同源异构：**底层框架一致，但具体意象、神名与叙事各有差异**。后世常以两地传说的互相印证。

### 2. 仙山（星银山脉）

分隔两地的星银山脉，在两侧文明的口述中不约而同地被神化为了 **“仙山”** 。

- **本质**：亚空间堰塞湖决堤的核心冲刷区之一，裂缝密集，洋能浓度极高。
- **传说中的面貌**：凡人不可踏足的禁地与圣山。山中云雾终年不散，异兽横行；唯有天选者方能登临山巅，或是借由仙山往返于两侧人间。
- **异常地质特征**：
  - 存在大量**无法解释的冲刷形成的结构**
  - 存在**极其怪异的已经干枯的地下暗河**
  - 这些特征是**堰塞湖决堤的物理痕迹**——承明前约3620年亚空间水冲入泡内时留下的冲刷印记
  - 星银山脉向北约**340km**就是飑髓的发现地点，即Lynx空难的发生地点
- **现状**：裂缝**依然存在**，没有闭合，洋能仍在持续渗透，星银山脉/洛神洋区域的**洋能水平依然偏高**（这也解释了为什么飑髓会出现在那个区域——它们可能被洋能吸引，或者洋能环境有利于它们的生存）。

### 3. 天外（南溟及周边海域）

若说仙山是陆地上的圣地与天堑，那么更遥远的南方海域——今**南溟**附近，在当时的传说中则被称为 **“天外”**。

- **本质**：南溟附近同样存在亚空间裂隙。峰值期间洋能水平足够高，来自亚空间的生物（"妖怪"）得以穿过裂隙进入地球活动，聚集在这一带。
- **传说中的面貌**：世界的尽头、群妖的来处。由于这里总有从亚空间过来的"妖怪"出没，吸引了一部分天选者远赴此地猎杀、探寻或定居，由此留下了大量关于"天外"的传说。
- **两地记载的差异**：
  - **西南文明**临近洛神洋与南溟，能更直接地接触从"天外"归来的天选者与海上异象，其传说更为具象，多涉及海上巨妖、远航与海岛。
  - **西北文明**对"天外"的认知全凭翻越仙山的天选者口耳相传，叙事更为抽象，往往将其描绘为极南尽头、水天相接的异界之地。


### 山脉的异常地质特征

- 存在大量**无法解释的冲刷形成的结构**

- 存在**极其怪异的已经干枯的地下暗河**

- 这些特征是**堰塞湖决堤的物理痕迹**——承明前约3620年亚空间水冲入泡内时留下的冲刷印记

### 现状：裂缝仍在，洋能偏高

- 那些裂缝**依然存在**，没有闭合

- 洋能仍在从亚空间持续渗透

- 星银山脉/洛神洋区域的**洋能水平依然偏高**

- 这解释了为什么飑髓会出现在那个区域——它们可能被洋能吸引，或者洋能环境有利于它们的生存

## 峰值期间的现象

### 亚空间生物入侵

高洋能环境下，维度界面的稳定性下降。泡内的复用区出现大量指针偏移——裂缝。

亚空间生物通过裂缝进入泡内。多数为低智慧的浮游层与巡游者种群，但有零星记录暗示，某些更大型、更智慧的存在也曾短暂出现于泡内。

这些生物在峰值结束后多数无法存活：泡内的洋能浓度虽然在峰值期间极高，但仍低于亚空间。当峰值衰退，洋能浓度骤降，依赖洋能维持生命的亚空间生物迅速消亡。它们的残骸、它们的行为模式、它们给人类留下的印象，被编织进了后世的传说中。

> 沧溟渡传说中那头"比船体大得多，表面没有鳞片，有缓慢流动的光纹"的巨兽，可能是某种深渊种在高洋能环境下进入浅洋甚至海面的罕见记录。它没有攻击那个渡海之人：它可能根本没注意到他。

## 沉渊与妖怪

峰值时代开始时，洋能浓度在短短一个月内剧烈涌出至当代的千倍上下，亚空间水的灌入使全球海平面上升了约十二厘米。如此剧烈的跃变之下，即便是无感的普通人也无处可逃，全球约九成人类受到洋能的不利影响，发生沉渊等症状；少数在洪流中仍能驾驭洋能的人，则由此被称作天选者。

这不是现代意义上的"跨越者"——跨越者是镜像底层被洋能覆写但仍保持自我的个体。峰值时代的沉渊是大规模的、失控的洋能冲击，大部分受影响者失去了自我，变成了被洋能驱动的存在。

**妖怪的来源**：许多后世传说中的"妖怪"，本质上是沉渊后的人类或其他生物。他们失去了原本的形态和意识，被洋能改造成了非人的存在。240年的峰值期足以让这些"妖怪"成为文明记忆的一部分，被口述、被神化、被编织进神话。

**其他生物**：除人类外，动物、植物、甚至某些微生物都可能在高浓度洋能环境下发生变异，成为后世传说中的"异兽"或"灵物"。

**天选者与妖怪的两面**：同一个时代的两面。成功驾驭洋能的人成为"英雄"或"天选者"，被洋能反噬的人成为"妖怪"。区别不在于谁更强，而在于谁保持了自我。

**峰值时代结束后的结局**：不同妖怪有不同的结局：
- **消亡**：大部分妖怪依赖洋能维持，洋能衰退后无法存活
- **退回亚空间**：部分妖怪可能退回亚空间，或在裂隙附近残存
- **残存于传说**：少数可能以残缺形态留存于人间，成为传说

## 为什么没有记录

| 原因 | 说明 |
| - | - |
| 裂隙隐蔽 | 裂隙在深山深海、甚至被压在山体下，人类无法发现 |
| 记录方式 | 文字在峰值初期的浩劫中失传。240年足以让围绕天选者的宗教文明重新发展初级的记录方式，但衰退期的动荡导致大部分记录散失 |
| 来得太突然 | 峰值的起始没有预兆，当人们意识到"世界变了"的时候，峰值可能已经过了数十年 |
| 衰退期动荡 | 四百年的衰退期中，社会经历了剧烈动荡，文字记录在战乱中散失 |
| 神化倾向 | 人类倾向于将无法解释的现象神化。240年的"奇迹"在口述中被不断放大，最终变成了神话 |
| 妖怪记忆 | 沉渊后的人类和生物成为"妖怪"的记忆，在口述中被扭曲、夸大，形成了后世的志怪传说 |
| 不被当真 | 就像现实中的上古神话，没有人认为这些传说是真实发生过的事 |

### 失真的形式

| 形式 | 说明 |
| - | - |
| 时间错位 | 事件被移置到不同的年代。一个发生在峰值第30年的事件，可能被记录为"上古时期" |
| 人物合并 | 多个天选者的事迹被合并到一个人身上，形成"超级英雄"式的传说 |
| 因果倒置 | 人们用结果解释原因。"他能飞是因为他是神"，而不是"他能飞是因为洋能浓度足够高" |
| 细节丢失 | 具体的技术细节（如何使用洋能、如何感知亚空间）在口述中丢失，只留下"他做到了什么"的叙事 |
| 地域混淆 | 不同地区的传说互相渗透，形成矛盾的地理描述 |
| 妖怪神化 | 沉渊后的人类和生物被神化为"妖怪"或"神兽"，失去了原本的悲剧性 |

> 今人读到的每一个前魔力时代传说，都是峰值时代的一个碎片。碎片与碎片之间无法拼合，因为它们来自不同的地域、不同的口述者、不同的神化方向。


## 天选者

> 设定文档中也使用"英雄"或"洋能驾驭者"称呼同一群体。

峰值期间出现的洋能驾驭者，在现代流传的神话中被称为"天选者"。

他们不是现代意义上的"跨越者"——那个概念建立在镜像机制的学术理解之上，而承明前约3620年没有这种理解。他们是什么？没人知道。

一种可能是：在极高洋能环境下，某些人类的镜像系统在自然轮换中被洋能覆写的概率大幅上升。峰值期间的"跨越者"可能比现代多出数个数量级。

另一种可能是：峰值期间的洋能浓度高到可以被人类直接感知和调用，无需跨越镜像的门槛。就像一个人站在齐腰深的水中，不需要学会游泳也能被水托起。

无论哪种情况，这些人被当时的社会称为：英雄。神。天选者。圣者。名称因地域而异，含义相同：能做到常人做不到的事的人。他们不是传说中那样。但传说也没有完全说错。

### 延续数代的群体

"天选者"不是一代人，而是延续数代的群体。240年的峰值期足以让洋能驾驭者形成传承——上一代的经验口述给下一代，下一代在此基础上发展出自己的技巧。这不是现代意义上的"师徒"或"门派"，更像是一种松散的、跨代际的知识传递。

### 能力

峰值期间的天选者，能力范围远超现代的低阶跨越者。这并非因为他们更强，而是因为环境洋能浓度极高——就像一个现代的游泳冠军和一个古代的渔民在暴风雨中的海里，技术差距被环境抹平了。

| 能力类型 | 推测范围 |
| - | - |
| 肉身强化 | 远超玄境极限。可能接近现代的归境 |
| 魔力操控 | 粗糙但强大。能级可能达到烈（M）层 |
| 感知扩展 | 可以感知到远处的生命体、地形、甚至亚空间裂缝的位置 |
| 环境影响 | 局部改变气候、影响动植物生长、修复或破坏地形 |
| 跨维度感知 | 零星记录暗示，部分个体可以"看到"或"感觉到"亚空间的存在，但无法命名或理解 |

这些能力在现代的能层能级体系中可以被对标，但对标本身没有意义，他们不知道自己在"对标"什么。

### 结局

峰值结束后，洋能浓度缓慢衰退。天选者们经历了什么？

| 可能性 | 说明 |
| - | - |
| 能力消失 | 最普遍的情况。洋能衰退后，镜像覆写层失去能量供给，镜像出现破损，但记忆仍在 |
| 身体崩溃 | 部分个体可能因洋能依赖过深，在能量断供后出现严重的镜像缺失。可能在衰退期内死亡 |
| 隐退 | 少数个体可能保留了部分能力（残余洋能足够维持基本功能），选择隐居，将经历口述给后人 |
| 消亡 | 极少数可能在峰值期间已彻底亚空间化（生命形式转变），衰退期结束后无法在低洋能环境中存活 |

> 没有"英雄不死"的结局。他们中的大多数，在四百年的缓慢衰退中，逐渐变成了普通人。少数变成了传说。

### 已知

- 有天选者**去了亚空间**

### 留白

- 进入亚空间的天选者有多少？他们在那里经历了什么？

### 疑似证据

星银山脉的深山中，考古人员陆续发现了一些异常的人形尸骸。

这些尸骸的骨架结构大体符合人类特征，但许多个体明显多出了人类不应该拥有的器官：翅膀、多余的手臂、多余的眼睛、尾骨延伸出的骨质结构。数量不多，分布零散，保存状态差异极大。

学术界将这些发现归类为"上古文明遗迹"——一种已经消失的、可能拥有不同生物工程水平的早期文明留下的遗骸。这个解释被广泛接受，因为人类对"已消失文明"的想象力远大于对"神话可能是真的"的接受度。

没有人把这些尸骸与神话中的天选者联系起来。那是神话。这是考古。两件事。

## 神话地位

洋能峰值时代留下的传说，在后世的地位类似现实中的后羿射日、女娲补天、山海经——是"古人的想象"，是"文化符号"，是"不能用科学解释的上古记忆"。

没有人把这些传说当真。

它们与后来的历史事件无关。那些是各自独立的历史，发生在洋能峰值结束很久之后。

> 在现代流传的神话中，峰值期间出现的洋能驾驭者被称为"天选者"，而那些沉渊后的人类和生物被称为"妖怪"或"神兽"。
