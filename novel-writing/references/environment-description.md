# 环境描写（写景传神六法）

写景之难不在堆砌、不在摹形，而在**传神**——让风景"开口说话"。用于：升级五感堆砌式景物描写、用环境烘托心境与氛围。

新手误区警示：机械套用五感法（视觉一句、听觉一句、嗅觉一句……挨个打卡），或堆砌高大上成语。五感只是基础工具（见 `visual-writing.md`），高级环境描写只需几句话就传达心境。

## 六法

### 1. 动态视角

让景物随人物的足迹与情绪而动，视角在画面中移动扫荡。

- 范本：老舍《骆驼祥子》暴雨下的北平——"风带着雨星，像在地上寻找什么似的，东一头西一头地乱撞……风，土，雨，混在一处，联成一片"。画面动荡不安，恰是祥子内心挣扎的外化。

### 2. 景物拟人化

赋予无生命景物人的动作、情感或特征，让景物活起来。

- 范本：莫言《红高粱家族》——"风像一个喝醉酒的汉子，摇摇晃晃地走着，发出低沉的吼声，把高粱的叶子撕扯得哗啦啦作响。"

### 3. 赋予色彩和特征

给景物带上感情色彩与独特特征，瞬间传达意境。

- 范本：张爱玲《金锁记》——"三十年前的月亮……像朵云轩信笺上落了一滴泪珠，陈旧而迷糊。""陈旧而迷糊"的泪珠色月光，把读者拽入压抑扭曲的回忆深渊。

### 4. 跨感官通感

用一种感官的词语描绘另一种感官："甜美的歌声""刺眼的阳光"。

- 范本：余华《活着》——"麦子的香味浓郁得仿佛能听到它们在风中低语的声音，那声音带着阳光的暖意和泥土的芬芳。"（嗅觉→听觉→触觉连环转化。通感基础见 `visual-writing.md`。）

### 5. 留白胜于堆砌

高级写景懂得在语言中"后退一步"，不直写情感，用细节让情感自行流淌。

- 范本：汪曾祺《受戒》结尾——"芦花才吐新穗。紫灰色的芦穗，发着银光……野菱角开着四瓣的小白花。惊起一只青桩，擦着芦穗，扑鲁鲁鲁飞远了。"未直写少年情愫，水鸟惊飞、芦穗轻摇中清澈懵懂的悸动自在流淌。（留白原理见 `art-of-omission.md`。）

### 6. 借用人文符号

调用文化共通的象征符号，一词激活一片氛围。

- 范本：鲁迅《药》结尾——"只见那乌鸦张开两翅，一挫身，直向着远处的天空，箭也似的飞去了。"乌鸦象征不祥与死亡，骤然飞走，悲凉氛围瞬间立起。

## 诊断要点

- 是否五感挨个打卡、平均用力？→ 只取服务心境的一两个感官，或用通感打穿
- 是否成语堆砌？→ 换成动态视角与拟人，让景物自己"演"
- 景物是否与人物心境脱节？→ 环境是心境的外化（祥子的暴雨），写人先看景、写景先问心
- 是否把情感说尽了？→ 学《受戒》后退一步，留细节给读者
- 是否有现成文化符号可用？→ 乌鸦、残月、落叶等传统符号一词顶一段
