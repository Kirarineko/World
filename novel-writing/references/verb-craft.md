# 动词炼字（用动词代替形容词）

核心主张：形容词是静态的结论、模糊的概念；动词让读者身临其境。用于：把"贴标签"式描写改成"演出来"的描写、用动词刻画性格。与 `visual-writing.md`（场景画面感总法）和 `show-dont-tell.md`（展示优于陈述）联动；本篇专攻动词选择本身。

## 形容词滥用的三大问题

1. **静态与抽象**："他很愤怒" 不如 "他拳头攥得'咯吱'作响"——动作展示愤怒。
2. **主观与模糊**："一个可怕的夜晚" 不如 "窗外的风凄厉地撞击着玻璃，树影在墙上扭动如鬼魅"——形容词因人而解，动词形成统一画面。
3. **信息量有限**："那座宏伟、古老、壮观的城堡" 不如 "城堡耸立在悬崖边，石墙边攀爬着常春藤，塔楼刺破云层"——堆砌形容词累赘且信息密度低。

注意：不全盘否定形容词。"他有一头金色的卷发"中"金色"清晰明了，难用动词替代。原则：**关键处（氛围、细节、动态）优先动词，定位性属性可用形容词；不为用动词而用动词。**

## 四招用好动词

### 1. 用动词描绘"特质"（核心中的核心）

不仅用动作写瞬时情绪，更用**一贯的行为模式**揭示稳定性格。问自己：这种性格的人通常怎么做？

- 弱（标签）：他是一个谨慎的人。
  强（展示）：他反复检查门锁，小心翼翼地把文件对齐，说话前总要停顿片刻，眼神仔细扫视四周。
- 弱（标签）：她性格冲动。
  强（展示）：她拍案而起，话语像连珠炮一样出来，不等别人说完就打断，拿到东西就猛地转身冲出门去。

### 2. 精选"性格化"动词，告别千人一面

同一基础动作，不同性格不同动词：

| 基础动作 | 性格 | 动词选择 |
|----------|------|----------|
| 走路 | 自信者 | 昂首阔步、稳健地迈步 |
| | 胆怯者 | 蹑手蹑脚、畏缩地挪动、低头疾走 |
| | 懒散者 | 慢吞吞地晃、拖着脚步走 |
| | 急躁者 | 匆匆奔走、大步流星 |
| 说话 | 强势者 | 命令、断言、质问 |
| | 温和者 | 低语、建议 |
| | 狡猾者 | 暗示、诱导、含糊其辞 |
| | 直率者 | 直言、挑明 |

### 3. 利用"微动作"，细节处见真章

不经意的小动作是性格的泄露口，用精准动词捕捉：

- **一丝不苟**：下意识抚平衣服褶皱、调整桌角物品、擦拭一点污渍
- **焦虑不安**：不停搓手、抖腿、啃咬指甲、眼神飘忽
- **傲慢自负**：习惯性抬高下巴、轻蔑地瞟人、手指有节奏敲击桌面

### 4. 强弱动词对照，告别"万金油"

挖掘更具表现力的动词替代弱动词（走、看、说、拿）：

| 弱动词 | 强动词（附情绪色彩） |
|--------|----------------------|
| 他走进房间 | 闯进（冲击/鲁莽）、溜进（鬼祟/秘密）、踱进（悠闲/沉思）、蹒跚进（疲惫/年迈/受伤） |
| 她看着他 | 凝视（专注/深情/严肃）、瞥一眼（快速/轻视）、瞪着（愤怒/不满）、打量（审视/好奇） |

选择取决于要传达的具体情境与人物心态。

## 诊断要点

- 句中是否有"很/非常 + 情绪形容词"？→ 换成动作展示
- 是否形容词三连堆砌（宏伟、古老、壮观）？→ 换成三个动词
- 角色性格是否靠旁白宣称？→ 设计一贯行为模式，用动词演出来
- 同篇角色的"走/看/说"是否千人一面？→ 按性格动词库区分
- 是否有为动词而动词的生硬句？→ 自然度优先
