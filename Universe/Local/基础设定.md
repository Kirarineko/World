
# 本地泡基础设定

## 行星与星系

| 条目 | 设定 |
|------|------|
| 星系 | 本泡有 **7 颗恒星**，散落在约 4–115 光年的尺度里。其中 1 颗是双星系统，其余 5 颗是单星 |
| 主行星 | 地球 |
| 卫星 | 月球 |
| 泡壁位置 | 远在探测器可及范围之外，包裹整个星团。人类造物还没碰到过它 |
| 星空 | 真实恒星（7 颗中的 6 颗在夜空中肉眼可见）加上泡壁外的高斯泼溅形成的光点 |
| 星空认知 | 人类一直以为看到的星星都是真实恒星。因为映射关系，高斯泼溅光点在视差、自行、光谱上都像真的，天文学上也分不出来。|


## 宇宙认知

人类仍然按传统大爆炸宇宙学理解宇宙。泡模型不在任何主流学术框架里，人类的探测器还飞不出太阳系，也没碰到过什么异常边界。他们完全不知道亚空间的存在，也**完全不觉得自己活在泡里**。


## 智慧断崖与本地泡

整个泡宇宙里，智力在“猫”附近有巨大的断崖。能把文明搭起来的智慧物种，少得离谱。本地泡偏偏是少数例外之一。


> 详细机制见 `镜像机制.md`。

原因出在镜像。镜像要吃神经资源，得拿去维持引用计数、差分层、块释放这些东西。别的泡大多把资源砸进镜像里，生命力普遍强，但脑子也就那样。本地泡精简了镜像，省下来的资源拿去养认知，提高了平均下限。

代价就是寿命短，更容易衰老。

## 国家

单个巨型国家，约80年前沉渊战争时形成，直到20年前名为人类联合国，此后改名为地球联合国。

社区的态度没有太大变化，能够包容跨越者的城市/社区还是一只手能数过来，大部分的虽然消除了一些偏见，但还是不太能正常生活，包括雾城在内的个位数城市任然仇视跨越者。

虽然法律写明了跨越者有人格尊严，但还是难以约束一整个城市的社区行为，甚至引起了部分洁癖派组织对国家的不满

### 历法

**承明历**：以联合国建国为元年，今年为承明历81年。联合国建国前的历史纪年方式已不常用，现代官方文件、历史记载、建筑年代等均以承明历标注。

### 边陲

边陲地区大部分是不宜居地带，居民已适应严酷环境，能勉强或正常生存。部分聚落自立为国，地联未关注，也未出兵，无资源价值。

## 社会治理

本泡人类文明的社会治理跨度极大。从大城市到偏远村落，治安状况差异悬殊。


### 治理结构

| 层级 | 治安情况 | 例子 |
|------|---------|------|
| 大城市 | 和现实相似的治安 | 昭明京、白虹城 |
| 中型城市 | 可能因江湖人聚集出现江湖风气 | 雾城（有一点），星月湾（独特表现）|
| 小城市 | 有江湖风气，表现形式各异 |  |
| 山区/丘陵/湿地区小镇小村落 | 江湖气息浓厚 | 云梦泽内部村落 |

社会治理松散有其根本原因。陆地宜居地区占比远超现实，人口密度低，人少地大。联合国划入地盘的地区不一定被管理，真正被联合国治安管理的地区只占6%。黑户政策宽松，联合国对黑户管得不严，不会主动去抓，民间也几乎不关心黑户。

### 江湖风气

江湖风气不是所有地方都有，但分布广泛。表现形式因地区而异。

偏远地区的小镇小村落江湖气息最浓厚，人少地大，政府管辖不到，自然形成自己的秩序。中型城市可能因江湖人大量聚集出现江湖风气。小城市的江湖风气表现形式更独特，比如星月湾的江湖人士可以是二次元，如果出现魔法少女行侠仗义这种奇妙的画面那基本就可以确定至少有一拨人来自星月湾。


### 与边陲的关系

边陲地区（不宜居地带）的聚落自立为国，地联未关注、未出兵。这是治理松散的极端案例。

## 力量社会


社会对力量的态度是**公开**的。武者和魔法师的存在是公开信息，不是秘密。

跨越者近20年开始可以共存，接受度在部分城市缓慢上升，但绝对数量比较少。残余阻力依然存在，洁癖派还是会拿碳基纯洁性说事，政治上还留有不少权力。

## 魔力与科技

| 条目 | 设定 |
|------|------|
| 能量名称 | **魔力**：九十七年前正式命名；**洋能**：几年后由科考队命名，指代星银山脉发现的特殊能量（详见 `洋能.md` 与 `洋能信息机制.md`） |
| 科技基准 | 大致相当于21世纪 |
| 魔力参与度 | 不算高。它太吃个人体质，没法稳定量产 |
| 魔力储能 | 能量密度比锂电池高约20%，但得人工灌魔，产能一直卡着 |
| 魔力武器 | 有，但很少，基本算特种装备 |
| 热武器 | 存在轻型自动热武器，但数量稀少，城市内严格禁持，野外因维护困难与弹药匮乏极少使用 |

### 洋能的信息底层机制

洋能在深层物理本质上是由十六种离散共振频谱基元（谱元）构成的有序信息载体。谱元首尾相连拼接成一维谱链，并通过相位共轭互补在三维空间中自发折叠为功能性的立体构型（谱）。谱表面的微观共振腔（活性口袋）通过与现世物质的分子极性或共价键发生同频共振，从而实现对现实世界的物理干涉。高度精密的高阶谱更具备自催化复制能力，解释了沉渊潮的自持蔓延与活体共生建材的长期生态循环。

该机制属于洋能介质本身的客观物理属性，与生物修炼掌握的能层能级（单线程带宽与并发线程数）完全解耦，且在世界观内部属于人类学术界尚未认知的纯底层元法则。详见 `洋能信息机制.md`。

### 轻型自动热武器与边缘现状

文明科技树中存在轻型自动热武器（冲锋枪、轻型自动步枪与手枪等），但在社会中的实际存量与流通量相对稀少：

- **城市管制**：在各大主要城市与定居点内，法律基本严厉禁止个人持有任何形式的自动热武器，属于严控违禁品；
- **野外困境**：在缺乏执法的非城市、边陲及荒野地区，也极少有人使用热武器。主要是因为专用弹药难以寻获与补给，精密的机械结构在野外恶劣环境和魔力扰动下极难维护修理，一旦发生故障几乎无法自行排障；
- **力量替代与认知**：在生存防卫上，除非是完全极端抗拒、坚决不接受接触任何魔力的原教旨群体，绝大多数人都会选择冷兵器结合基础魔力、武力或魔导工具。**需要明确的是，并不是只有跨越者才能利用魔力**——未跨越的普通人类同样可以修习武道（金玄归天）或运用基础魔力；“跨越者”在医学与法理上的唯一定义是**“跨越了人类生理定义边界之人”**（碳基生理指标已偏离独立存活阈值但因洋能覆写存活），而非单纯以是否使用魔力划分。

魔力并非九十七年前才"出现"，它一直存在，只是后来才被正式命名。早期的修炼体系到后期基本都要依赖魔力，只是各地说法不一。修炼者基数极低时，沉渊也偶有发生，但无法引起链式反应，多被认为是"走火入魔"或类似的东西。
