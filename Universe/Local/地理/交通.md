# 交通

> 整体科技水平与现实21世纪相当，但航空业科技水平约相当于20世纪80年代，规模却更为庞大。

## 概述

本泡人类文明的交通体系以航空为核心，铁路和公路为辅。

航空业的科技水平约相当于20世纪80年代：飞机设计更老式，导航系统依赖地面台站，机场设施相对简单。但航空业的规模却远超科技水平——机场数量更多，航线网络更密集，票价相对亲民。主要城市之间普遍有直飞航线，长途出行首选航空。

高铁存在但线路有限，只有主要城市之间有直达，更多依靠普通铁路和航空。

## 铁路

### 高铁

| 条目 | 说明 |
|------|------|
| 时速 | 约320km/h |
| 线路 | 只有主要城市之间有直达线路 |
| 覆盖 | 有限，主要连接一线和新一线城市 |
| 定位 | 相邻城市之间的快速通道 |

高铁线路集中在大陆内部的经济发达区域。中小城市没有高铁站，需要先到大城市中转。

### 普通铁路

| 条目 | 说明 |
|------|------|
| 时速 | 100-200km/h不等 |
| 线路 | 覆盖广泛，深入中小城市 |
| 定位 | 高铁未覆盖线路的主要承担者 |

普通铁路是中小城市的主要铁路交通方式。票价低廉，速度较慢但覆盖面广。

## 航空

### 科技水平

航空业的科技水平约相当于20世纪80年代：

| 条目 | 说明 |
|------|------|
| 飞机设计 | 更老式，类似70-80年代的机型 |
| 座舱 | 传统机械仪表或早期电子仪表，没有现代玻璃座舱 |
| 导航 | 依赖地面导航台，没有现代GPS导航 |
| 自动驾驶 | 早期系统或没有 |
| 空中交通管制 | 传统雷达管制，没有现代卫星管制 |
| 机场设施 | 相对简单，没有现代的自助值机、生物识别等 |

### 规模

尽管科技水平不高，但航空业的规模却远超现实：

| 条目 | 说明 |
|------|------|
| 机场密度 | 主要城市普遍有国际机场，部分城市有多个 |
| 航线网络 | 主要城市之间普遍有直飞航线 |
| 票价 | 相对亲民，普通人可以负担 |
| 航班频次 | 热门航线每天多个班次 |

### 地位

航空是大陆间长途出行的首选方式：

- **效率**：大陆面积广阔，城市间距大，航空比高铁快得多
- **覆盖**：航线网络比高铁更密集，几乎所有城市都有机场
- **成本**：票价亲民，普通人可以负担

### 与高铁的关系

航空和高铁各有分工：

| 距离 | 首选方式 | 原因 |
|------|---------|------|
| 500km以内 | 高铁或汽车 | 距离短，航空优势不明显 |
| 500-1500km | 看情况 | 高铁和航空竞争区间 |
| 1500km以上 | 航空 | 距离长，航空效率优势明显 |

### 代表性航空公司

- **承天航空**：联合国直属航空公司，航线覆盖四大洲
- 其他航空公司待展开

## 航运

### 定位

沿海城市和岛屿之间的货运和客运。

### 主要航线

- 大陆间货运航线
- 沿海城市间的客运航线
- 岛屿城市的补给航线

## 公路

### 定位

城市内部和短途出行的主要方式。

### 特点

- 城市内部：公共交通+私家车
- 城际短途：高速公路
- 偏远地区：路况较差，部分区域无铺装路面
