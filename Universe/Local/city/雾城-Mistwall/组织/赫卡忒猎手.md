# 赫卡忒猎手

> 以魔法女神命名，却专门猎杀与魔法相关的人。

## 概述

赫卡忒猎手（Hecate's Hunter）是雾城的一个地下组织，专门狩猎跨越者和其他受洋能影响的生物。成员分布在城市中，低调运作，不会引起注意。

组织结构半正式：有核心圈子和外围成员，但没有严格的招募流程和统一领导。成员之间通过信任链联系。

## 组织结构

| 层级 | 说明 |
|------|------|
| 核心圈子 | 资深成员，决定行动目标和策略 |
| 外围成员 | 执行任务的猎手，流动性较大 |
| 信任链 | 成员之间通过信任联系，没有严格的招募流程 |

## 成员背景

赫卡忒猎手的成员背景混合：

- **退役军人**：沉渊战争时期的老兵，有战斗经验
- **普通人**：因沉渊战争失去亲人的普通人，出于仇恨加入
- **专业猎手**：专门训练过的跨越者猎人，以狩猎为职业

共同点是对跨越者有敌意——或出于仇恨，或出于理念。

## 与洁癖派的关系

赫卡忒猎手与洁癖派理念相近，但独立运作，没有隶属关系。

- 不是洁癖派的武装力量
- 不执行洁癖派的意志
- 可能在信息上有交集，但保持独立

## 与雾城官方的关系

雾城官方对赫卡忒猎手的态度是**不作为**：不想管，也没能力管。

- 官方知道赫卡忒猎手的存在，但不主动干预
- 只要死的是确认跨越者，官方就只会走流程查一查
- 一旦引起其他等级高于雾城的城市政府注意，不会收到保护

## 行动方式

| 方式 | 说明 |
|------|------|
| 暗杀 | 一般是刺客，复杂暗杀，不公开 |
| 目标确认 | 只针对确认的跨越者，不随意扩大目标 |
| 低调 | 不会引起公众注意，行动隐蔽 |

## 历史事件：公开日后的游行与爆炸

约二十年前，公开日后不久，赫卡忒猎手发动了一次重大行动。

### 背景

公开日后，雾城有部分市民转换态度，开始接受跨越者。在少数跨越者的组织下，这部分市民和几乎所有跨越者上街游行。

市政府的态度有些动摇，认为消除偏见对城市的未来有益，于是默许了这场游行。

### 赫卡忒的行动

赫卡忒猎手发现了这场游行，开始采取行动：

1. **匿名威胁**：通过各种渠道匿名威胁游行组织者
2. **暗杀**：发现威胁无效后，暗杀了几个人并匿名传播
3. **效果不强**：只让一些不那么坚定的普通市民退缩了
4. **大爆炸**：最终发动炸弹袭击

### 爆炸结果

赫卡忒的目标是跨越者精英，想着"擒贼先擒王"。但他们远远低估了跨越带来的体质提升。

| 伤亡 | 数量 | 说明 |
|------|------|------|
| 跨越者死亡 | 9人 | 没有一位是他们想杀的精英跨越者 |
| 平民死亡 | 91人 | |
| 重伤 | 280人 | |

爆心附近的跨越者也只是被炸飞后重伤，立即被附近的跨越者同伴带着离开了这座城市。

### 后续

- **联合国注意**：这场袭击引起了联合国的注意
- **市政府切割**：雾城名义上还是联合国的一员，享受着各种扶持，市政府当机立断切割，把赫卡忒供了出去
- **赫卡忒低调**：本身就是地下组织的赫卡忒变得更加低调
- **保护失效**：市政府不管，但一旦引起其他等级高于雾城的城市政府注意，也不会收到保护

### 赫卡忒的自我评价

赫卡忒内部认为这场袭击是**胜利的**。他们认为这场爆炸把跨越者重新打回了下水道。

实际上，唯一的成果就是让跨越者对这座城市彻底失望。

## 名字来源

赫卡忒（Hecate）：希腊神话中的魔法女神。

名字带着讽刺意味：以魔法女神命名，却专门猎杀与魔法相关的人。

## 与雾城氛围的契合

雾城是洁癖派核心支持城市，对跨越者仇视。赫卡忒猎手是这种氛围下的极端产物。

官方不作为，为猎手提供了行动空间。而公开日后的爆炸事件，又让赫卡忒在雾城的地下世界中获得了某种"战绩"——尽管这个战绩的水分很大。
