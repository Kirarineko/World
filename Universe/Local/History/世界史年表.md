
# 世界史年表

> 本表为全库年代的唯一权威源。正文各处年代表述一律以本表为准。
> 本表覆盖本泡人类文明的关键历史节点，从前魔力时代到当代，并附冲突裁定记录。
> 全表统一使用承明历纪年：建国后记承明历 X 年，建国前记承明前 X 年。

## 纪元换算

| 项目 | 规则 |
|------|------|
| 今年 | 承明历 81 年 |
| 建国 | 承明历元年，约当承明前 1 年末至元年（人类联合国在沉渊战争过程中建立） |
| 承明历 X 年 | 距今（81 − X）年 |
| 承明前 Y 年 | 距今（80 + Y）年，即元年前 Y 年 |
| 具体月日 | 正文已有者（如 81 年中秋、11 月 28 日）沿用 |

## 三重时间

这条时间线里，有三道很明显的分界。

**第一道，承明前约三千六百二十年的洋能峰值。**

那二百四十年里，洋能浓度高得不正常。奇迹、怪谈、英雄、妖怪，全都挤在一段漫长的时光里冒出来，后来又一起退潮，只剩下口耳相传的零碎和一些怎么都解释不干净的传说。很多旧故事的根子，大概都埋在那时候。

**第二道，承明前约十七年的洋能命名。**

在那之前，人们知道武力，也知道有人能靠修炼把身体练得很强，但没法把背后的能量说清楚。后来它终于有了名字，叫魔力。从命名到如今不过百年，档案馆里还留着这个词第一次登报时的报纸。

从那以后，许多旧谜团才开始重新有了说法。沧溟渡、残灯录、梦台，这些东西不再只是怪谈，而像是更早一轮奇迹留下来的碎片。
