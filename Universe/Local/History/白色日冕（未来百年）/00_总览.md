# 白色日冕 · 纪元总览

> 当地球自身的重力开始点燃渗透而来的洋能，太阳便不再是唯一的火炉。暴沸的海洋将水汽抛向太空，纯洁的碳基神话在八十度的酷热与骤降的气压中化为焦土。那一刻，曾经被视为深渊的异世界，成了这颗星球上生命唯一的诺亚方舟。

---

## 一、纪元概述

“白色日冕”是指承明历约一百二十年至二百二十年间，由于本地泡亚空间洋能渗透水平持续攀升，在地球表面引发的一场前所未有的行星级热力学与生态大裂变。

在过去的数千年中，本地泡的洋能浓度相对稀薄，地球主要遵循经典物理与气象规律运行。然而，随着亚空间与本地泡之间的渗透率迈过临界阈值，地球作为一颗拥有标准重力的大质量天体，不可逆地触发了洋能在引力场作用下的微观释放反应。

引力放热叠加原有的太阳辐射，驱动全球平均气温一路突破八十摄氏度；伴生的均相分散压导致地表大气压急剧跌去近三分之一，致使地表水沸点大幅下降，亚热带至赤道海域陷入长达数十年的全面暴沸。自太空回望，巨量水汽柱撕裂大气层被抛入近地轨道又呼啸回落，使整颗行星呈现出宛如恒星日冕物质抛射般的狂暴白炽巨弧。

这一纪元彻底终结了人类旧有的地缘政治格局与碳基纯洁性叙事，迫使整个文明在灭绝绝境中开启了迈向亚空间的跨界面大迁徙。

## 二、危机演进阶段

```
【 预兆期（承明历约 120~140 年）】
洋能引力放热初显 ──> 全球均温逼近 40℃ ──> 海水蒸发加剧 ──> 水汽温室效应启动

【 暴沸期（承明历约 140~180 年）】
气压骤降近 1/3 ──> 水沸点跌破 90℃ ──> 亚热带至赤道海域暴沸 ──> 均温突破 80℃

【 日冕与迁徙期（承明历约 180 年以后）】
超临界对流喷射入轨 ──> 形成白色日冕天象 ──> 纯碳基生态崩溃 ──> 全面迁徙亚空间
```

### 1. 预兆期：正反馈的启动
洋能渗透率的平稳抬升首先在地表低纬度区域引发反常的地温上升。全球平均气温突破四十摄氏度，海洋表面蒸发速率显著加快。由于水蒸气本身即是极高效的温室气体，巨量水汽在大气层中迅速截留更多地面长波辐射，使得温室效应脱离了传统的碳排放平衡模型，进入不可逆的自发正反馈循环。

### 2. 暴沸期：沸点倒挂与全域沸腾
洋能释放伴生的微观分子间斥力在宏观尺度上展现为“均相分散压”，削弱了地球引力对大气层的整体束缚，地表大气压持续下降至原先的三分之二左右。气压骤降使得水的饱和沸点直接跌落至九十摄氏度以下。当赤道地表温度突破一百摄氏度、亚热带均温突破八十摄氏度时，江河湖海由“蒸发”彻底转变为“全域暴沸”。沸腾产生水汽的速率达到常规蒸发的一千倍以上，整个对流层被白炽湿热的蒸汽狂流彻底淹没。

### 3. 日冕期：行星水汽喷流
极其狂暴的全球热对流形成了直径数百公里的超级上升气流柱，将数以亿吨计的高温水汽直接轰入近地太空，随后在重力作用下沿抛物线回落。从深空或月球观测，地球化为一颗边缘剧烈抖动、翻滚着白色水汽抛射巨弧的暴烈星球。

## 三、文明与生态大分流

白色日冕纪元在生物学与政治学上引发了彻底的颠覆与重构：

| 群体 / 阵营 | 生存状态 | 最终选择与结局 |
| :--- | :--- | :--- |
| **纯碳基人类** | 肺呼吸、体温调节与水分循环全线崩溃；高温与低氧分压带来灭顶之灾 | 守旧派在封闭生态穹顶中逐渐凋零；太空派付出高昂代价建立轨道殖民地 |
| **洁癖派政治势力** | 赖以立足的“碳基纯洁性”沦为自杀咒语；社会动员力彻底瓦解 | 在历史的绝罚中分崩离析，避难所大多死于环境系统过载 |
| **跨越者与洋能生物** | 生命镜像底层依赖洋能维系，免疫高温与低压，在充沛洋能中身体机能反而大幅强化 | 成为救灾领航员，主导开辟通往亚空间的各大复用区通道 |
| **亚空间大迁徙** | 亚空间凭借天然气体分布、热力学对流自调节与无尽岛屿，成为文明唯一的新大陆 | 人类文明主体最终跨过维度界面，在亚空间建立全新的星岛城邦文明 |

## 四、历史评价

白色日冕纪元是本地泡文明有史以来最残酷的试金石，也是最宏大的新生。

它粉碎了凡人对单一行星家园的盲目依恋，打破了延续近百年的物种偏见与制度枷锁。曾经被主流社会视为异类、在星月湾偏安一隅的跨越者们，最终用双手推开了通往亚空间维度的生路大门。人类文明由此告别了单一星球时代，正式航向了那片广袤无垠的异度之洋。
