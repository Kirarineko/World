# 文明分流与道路之争

> 一部分人抬头望向漆黑冰冷的星空，宁可把自己封死在铁罐里；另一部分人跨过发光的虚无裂隙，走向那片被祖先诅咒了上百年的海洋。

---

## 终极分歧与地缘裂变

承明历150年代，地球联合国事实上已名存实亡。

面对不可逆的全球沸海与低压危机，最高议会就“人类文明的未来退路”爆发了持续十余年的大论战，最终分裂为两条决绝的道路：

```
                    【 地球联合国大分流 】
                                |
        +-----------------------+-----------------------+
        |                                               |
        v                                               v
【 太空派 (洁癖派 / 传统重工) 】               【 迁徙派 (星月湾 / HBI / 望城) 】
- 拒绝洋能异化，坚守碳基纯洁性                 - 拥抱跨越，将亚空间视作新家园
- 倾注产能建造轨道站与远征飞船                 - 研发指针相位锚定器，开辟维度通道
- 逃亡目标：月球轨道与深空真空                 - 迁徙目标：亚空间浅洋与温和群岛
```

## 太空派：钢铁孤岛与高昂代价

太空派主要由雾城洁癖派政治残部、北方传统重工业联合体以及部分执着于纯碳基纯洁性的保守平民组成。

他们的理念极为坚决：**“宁死于冰冷的真空中，也绝不成为洋能寄生的怪物。”**

在承明历150年至180年间，太空派动用了大陆仅存的重工业产能与火箭发射场，先后将三个巨型轨道生态环（“承明一号”、“洁渊”、“北辰”）和数十艘世代远征飞船送入近地与地月拉格朗日点轨道：

* **严酷的工程现实**：太空中没有洋能，维持了纯物理世界的法则，这确实保护了纯碳基免受洋能侵蚀；
* **脆弱的生存代价**：然而太空是绝对的真空与极寒。生态环必须时刻抵御致命的宇宙射线与微陨石撞击；维持人工气压、水循环与光合作用的设备每时每刻都在损耗有限的金属与聚变燃料；
* **孤立的下场**：在缺乏地面工业供应链支持的情况下，太空站逐渐陷入配件匮乏、舱体老化与人口负增长的绝望螺旋。

## 迁徙派：维度破障与技术破局

迁徙派以星月湾为大本营，汇聚了 HBI 泛生命科技学院、望城（皓月夜明算力中心）、海渊城（海洋与深渊研究所）以及全大陆绝大多数跨越者与开明派市民。

在茉璃（亚空间微内核原生生物）与望舒（炽·构天选者）的技术指导与经验支持下，HBI 的物理学家与湿件工程师取得了跨时代的突破：

1. **指针相位稳定器（TDM 锚定仪）**：
   通过高精度的洋能调制技术，人工锁定复用区微观时序指针的相位偏移步长，将原本随机、转瞬即逝的“裂缝”，固化为宽度可达数公里、常年稳定双向通行的**“维度长桥”**；
2. **多泡拓扑路由**：
   利用多空间复用区错位规律，不仅实现了地球与亚空间的直接穿梭，还勘测出了经由复用区直接连接其他宜居泡的快速安全航线；
3. **亚空间勘测与先遣队**：
   海渊城与 HBI 联合建造的介质探测船穿透裂隙，在亚空间浅洋中探明了数百座重力约为 $0.8\sim 1.0g$、拥有独立植被生态链且微气候温和的悬浮岛屿群落，为大规模移民绘制了详尽的《星海舆图》。
