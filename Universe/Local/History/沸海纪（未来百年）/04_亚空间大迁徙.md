# 亚空间大迁徙

> 八十年前，他们以为那是恶魔的巢穴与深渊；八十年后，他们才明白那是宇宙赐予新人类的无垠方舟。

## 亚空间宜居性的再发现

当第一批由 HBI 科学家、望城工程师与跨越者组成的联合先遣队穿过星月湾维度长桥、踏上亚空间的悬浮岛屿时，他们被眼前的景象深深震撼。

长达一个世纪以来，在洁癖派的宣传与民间的恐慌臆想中，亚空间被描绘为一片充斥着精神污染、狂暴洋溺与狰狞恶魔的黑暗地狱。然而，真实的物理法则展现出了意想不到的温柔：

1. **天然的恒温空调系统**：
   正如《亚空间志》中所记述，亚空间岛屿的引力吸附周边气体分子并激发温和的洋能释放反应，加热后的热气体上升膨胀、散热冷却后沉降循环。重力与地球相当（$\sim 1g$）的岛屿表面，常年维持在极其舒适的亚热带温和气温（$18\sim 25^\circ\text{C}$），没有酷暑与严冬；
2. **均匀充斥的气体介质**：
   在均相分散压的作用下，亚空间各岛屿之间的广袤空间并非真空，而是弥漫着柔和的气体介质。只要具备基础的洋能代谢能力，生命便无需佩戴沉重的增压宇航服；
3. **触手可及的星岛网络**：
   亚空间中没有恒星，各岛屿间距仅有数千至数百万公里，依靠成熟的介质动力船数天至数周即可往返，文明的交流与扩张成本远低于动辄以光年计的常规太空；
4. **无穷的清洁能源**：
   洋能弥漫在空气与地表，湿件计算机（Genius系列）、浮空飞舟与城市防卫力场拥有取之不尽的天然动力源。

## 跨界面大撤离（出埃及记）

从承明历175年开始，随着地球海平面常态化沸腾与超强台风频发，星月湾、望城、海渊城三大枢纽全面启动了人类历史上规模最宏大的跨维度迁徙工程：

```
                    【 跨 维 度 迁 徙 枢 纽 】
                                |
        +-----------------------+-----------------------+
        |                       |                       |
        v                       v                       v
【 星月湾 · 北湾长桥 】  【 望城 · 东山裂隙 】    【 海渊城 · 深海之门 】
- 泛生命科技与平民撤离   - 工业算力与大模型迁移  - 海洋生态与航海船队
```

* **城市级整体平移**：
  HBI 的湿件超级计算机、星澜与对影大模型的核心数据库、数千年文明积累的历史典籍、艺术馆与种子基因库，被模块化打包穿过裂隙；
* **跨越者领航与平民安置**：
  跨越者们利用散态（4d）与贯态（2p）能力在浅洋开辟了平静的航道，引导数亿移民登上一座座被命名为“新星月”、“苍梧”、“望舒之庭”的宜居岛屿；
* **生命形态的自然升华**：
  在亚空间高浓度洋能的长期浸润下，原本依靠防护服的普通人也在一代人时间内自然完成了良性的镜像覆写，平稳转型为适应新环境的新人类。

## 终局：两座文明的注视

承明历210年，地球表面几乎所有人类城市已全数沉寂于滚烫的白雾与呼啸的低压狂风中。

在近地轨道上，太空派残存的最后座生态环“洁渊号”依然在真空与辐射中艰难运转。透过空间站斑驳的观察窗，宇航员们俯瞰着那颗变成苍白雾球的母星；

而在同一时刻，地表数道巨大的发光维度裂隙深处，隐约透出亚空间千百座星岛如繁星般璀璨的暖色灯火。在那里，孩子们在没有重压的大地上奔跑，猫娘在阳光般温和的洋能光辉下晒太阳，诗人在记录着新大陆的航海日志。

曾经被人类深深恐惧的“异界”，最终接纳了人类所有的火种。
