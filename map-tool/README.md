# 世界观地图测量工具

虚构世界观地图的展示 / 测距 / 测面桌面工具。Electron + React + TypeScript。

## 启动

```bash
cd map-tool
npm install   # 首次
npm run dev   # 开发模式（热更新）
# 或
npm run build && npm start   # 生产模式
```

## 功能

- **目录扫描**：手动选择世界观目录，递归扫描图片；仅收录文件名包含 “map” 或 “地图” 的文件（大小写不敏感）
- **比例尺校准**：选择「校准」工具 → 用缩放条放大到指定倍率 → 在图例比例尺上拖出参考线 → 输入实际距离与单位，自动换算
- **测距**：直线 / 折线（单击加点，双击或回车结束）/ 自由画笔 / 三次贝塞尔（四个点，节点可拖动）
- **测面**：自由选区（单击开始、移动勾勒、再单击自动闭合）/ 多边形（顶点可拖动）/ 套索（按住左键圈选，松开闭合）
- **画布**：滚轮缩放（以光标为中心）、空格按住拖动、缩放倍率可直接输入、一键适应窗口
- **主题**：暗色 / 亮色，顶栏按钮切换
- **持久化**：比例尺与测量记录保存在地图图片同级目录的 `<图片名>.maptool.json`

## 目录结构

```
src/main/      Electron 主进程（目录扫描、配置读写、图片协议）
src/preload/   预加载脚本（IPC 桥）
src/renderer/  React 界面（画布、工具栏、侧栏）
```
