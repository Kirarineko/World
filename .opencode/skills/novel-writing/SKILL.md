# Novel Writing — 综合小说创作

## Overview

汇集小说创作各维度方法论的参考库，用于辅助叙事文学的创作、改写、润色与点评。各子主题以独立 reference 文件存放，按需加载，避免一次性占用上下文。

## 使用方式

1. 判断用户需求属于哪个子主题（见下方主题索引）。
2. 读取对应的 `references/` 文件，按其方法论执行创作、改写或点评。
3. 若需求横跨多个主题（如改写一段既平淡又对话生硬的文字），加载多个相关 reference 综合处理。

## 通用原则

- 改写用户原文时，保留其情节、人物设定与语气风格，只优化表达方式。
- 点评时先指出问题位置与原因，再给出改写示范，让用户理解"为什么"。
- 所有方法论服务于读者体验：让读者成为观察者而非听众。
