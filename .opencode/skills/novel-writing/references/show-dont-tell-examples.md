# 陈述 vs 展示 对照示例集

按场景分类的改写示范。改写时参照同类型示例的"证据组合"思路，而非照搬句子。

## 情绪类

### 生气
- 陈述：他很生气。
- 展示：他攥紧拳头，指节捏得发白，牙关紧咬，胸膛剧烈起伏，眼神像喷出火来。
- 证据组合：手部动作 + 牙关 + 呼吸/胸膛 + 眼神

### 害怕
- 陈述：他感到害怕。
- 展示：他心跳得像擂鼓，手心全是冷汗，喉咙发干，仿佛一只无形的手扼住了他的脖子。
- 证据组合：心跳 + 汗液 + 咽喉的躯体化感受

### 孤独与绝望
- 陈述：他感到孤独和绝望。
- 展示：他一个人坐在空旷的公交站台长椅上。天色渐晚，最后一班公交车刚开走，留下呛人的尾气（嗅觉+视觉）。路灯昏黄的光线勉强照亮一小片区域（视觉）。冷风卷起地上的落叶，发出沙沙的声音（听觉+触觉）。他抬头望天，一颗星星都看不到，只有厚重的乌云压在头顶（视觉+象征）。
- 证据组合：空旷场景 + 末班车离去 + 昏暗光线 + 冷风落叶 + 无星乌云（环境烘托心境）

### 不情愿
- 陈述：他不情愿地答应了。
- 展示：
  "所以，这事就这么定了？"她笑着问。
  他沉默了片刻，视线落在某个看不见的点上。然后，他抬起头，声音没什么起伏："……嗯。"
  "太好了！"（她似乎没察觉或者不在意他的勉强。）
  他只是扯了扯嘴角，没再说话。
- 证据组合：沉默 + 单音节回答 + 缺乏情绪的语气 + 敷衍的动作 + 再次沉默

## 人物特质类

### 聪明
- 陈述：她非常聪明。
- 展示：她只花了五分钟就指出了逻辑漏洞，并提出了三种可能的解决方案。
- 要点：用具体事件与可量化的结果代替评价词。

## 环境氛围类

### 寒冷
- 陈述：那是一个寒冷的夜晚。
- 展示：寒风像刀子一样刮过脸颊，他把脖子缩进单薄的衣领，呼出的白气迅速消散在昏暗的路灯下。
- 证据组合：触觉（风如刀割）+ 人物防御动作 + 视觉（白气、路灯）

## 五感速查

| 感官 | 关注维度 | 示例片段 |
|------|----------|----------|
| 视觉 | 颜色、光线、形状、动态 | 夕阳的余晖给窗棂镀上了一层温暖的金边 |
| 听觉 | 大小、远近、特质 | 雨点敲打玻璃窗，发出单调而持续的嗒嗒声 |
| 嗅觉 | 气味来源与浓度 | 刚割过的草坪散发出浓郁的青草气息 |
| 味觉 | 酸甜苦咸的直接体验 | 那杯咖啡苦涩得让他皱起了眉头 |
| 触觉 | 温度、质地、压力 | 粗糙的麻布摩擦着他的指尖 |

## 进阶技巧提示

- **言行不一致**：人物的语言与身体语言矛盾时，内心复杂性自然浮现。例：嘴上说"没关系"，手却在桌子下紧紧攥着。
- **情绪反应链**：外部刺激 → 生理反应 → 具体（甚至混乱的）思维片段 → 外显行为。四环相扣，读者才会感同身受。
- **冰山对话**：对话只展示水面上的八分之一；潜台词、省略、反语、停顿构成水下的八分之七。
- **环境即心境**：环境描写不只是背景板，可映射心境、预示情节（暴风雨前的压抑天空暗示危机）。
