# 复杂度构建（小说要一点一点写复杂）

复杂不是一次性堆砌到读者面前的，而是逐步展开的过程。用于：被宏大世界观/众多人物/多条线索吓住而迟迟无法动笔、或开篇信息倾倒吓退读者。与 `problem-driven-plot.md`（问题驱动主线）、`minimalist-prose.md`（舍设定）联动。

反面教材：开篇塞给读者几十个角色名、一套世界规则、一堆情节——大多数读者会直接弃书。

## 三步推进框架

### 1. 寻找切入点：一颗简单的"种子"

四类切入点任选其一：

- **人物切入**：主角在众人前被羞辱。
- **事件切入**：市长家的千金忽然失踪了……
- **疑问切入**：如果你家的猫变成了人，会发生什么？
- **场景切入**：一个被迷雾笼罩的古老村庄，似乎隐藏着什么秘密。

### 2. 逐步推进：先立骨架，再长血肉

切入点之后，先精准展示四要素：**主角是谁？想达到什么目的？主要冲突是什么？故事发生在怎样的环境？**

然后让复杂度自然生长：

- **关系网扩张**：主角起初只认识老师和同伴（基础关系网）→ 遇到新盟友、敌人 → 发现导师/同伴隐藏的过去 → 牵扯出新角色与势力。
- **支线并行**：逐步引入与主线并行的支线情节或次要冲突，共同推动故事。

### 3. 主题深化

最初也许只是简单的善恶对决，随着推进：善恶界限变模糊、人物动机变复杂、世界观展现更多细节。（普适主题的选择见 `reader-resonance.md`。）

## 四个落地操作

### 1. 从简单大纲开始

不一次性写完细纲。用简单三幕式起步：开端、发展、高潮、结局，每幕只列关键事件与人物目标。

### 2. 角色驱动复杂性

复杂的故事源于复杂的人物。每个角色有自己的目标、动机、秘密、矛盾——目标互相冲突、秘密逐渐暴露时，复杂性自然增加。拒绝单一善恶：盟友也有理念分歧，敌人也有可悲或可敬之处；行为动机可以是爱、恨、恐惧、欲望、责任的混合。

### 3. 不断提问

写作中持续自问：

- 如果这个角色做了不同的选择，会发生什么？
- 这个事件背后是否还有更深层的原因？
- 这个秘密被揭露后，会对其他人物产生什么影响？
- 我的世界观中还有哪些未被探索的角落？

这些问题会引导发现新情节线索与新人物关系。（即 `problem-driven-plot.md` 的问题驱动法在写作过程中的日常化。）

### 4. 修改出复杂

初稿是骨架，简单粗糙很正常。真正的复杂性在反复修改中浮现：

- **第一遍**：专注把故事讲完，不纠结细节。
- **第二遍**：填充细节、深化人物、完善世界观。
- **第三遍**：检查逻辑漏洞、增加伏笔和呼应（配合 `foreshadowing.md` 伏笔台账）、提升主题深度。
- **最后**：精炼语言（`minimalist-prose.md`）、打磨节奏（`pacing.md`）。

## 诊断要点

- 是否迟迟不动笔，被"复杂"吓住？→ 退回一颗种子：选一个切入点就开写
- 开篇是否信息倾倒？→ 只留四要素，其余延后揭示
- 角色是否单一善恶？→ 给盟友加分歧，给敌人加可敬之处
- 是否试图一稿到位？→ 按四遍修改法分层加工
