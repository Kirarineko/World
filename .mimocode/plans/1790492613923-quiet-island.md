# 望府设定文档编写计划

## 目标

新建 `宇宙/本地泡/城市/承明大陆/望城/望府.md`，写清望家府邸的建筑清单、家风气质与家族秘辛底色，并登记进望城索引。建筑清单需覆盖小说《归客照清辉》已定剧情的空间需求；**布局细节留空，待用户图稿定案后另补**。

## 背景要点（已确认 + 小说大纲校准）

### 府邸定位

- **位置与规模**：望城**郊区**，依山傍水；占地极广，规模接近一个独立小村落
- **建造方式**：**现代技术建造，古色古香建筑风格**（苏派形制：粉墙黛瓦、亭台楼阁、水榭回廊）。不是老城肌理里长出来的老宅，是望家择地新建的大府
- 布局构思参考芯片版图「功能块 + 总线」逻辑（主院落群、对称双附属、园林落在大块地、外围功能贴边）。**布局与芯片对应关系本轮不写入文档**，待图稿定案后处理；文档内亦不出现英文芯片名与行话

### 望家与城

- 世代经商，望恒一代转入科技（皓月夜明）
- 持有**望城 3.25% 股份**：老望城与重建新望城皆为主要贡献者；老望城近乎荒废的数十年间望家也未搬离
- 无姓氏登记时间线：公开日联合国提议并建成系统但无城市启用；**承明历60年望城第一个启用且免审批**（望家在其中推动）；至81年共12城支持，除望城与星月湾外均需审批

### 社会背景（后续剧情相关）

- **同性婚姻承明历76年合法化**，目前仅望城、星月湾、沧海京支持；后续有浅紫与茉璃、望舒与朔夜的相关剧情——望府文档里可点一句「府里对此的态度」（自然是无所谓/乐见）

### 家族秘辛与家风

- 族谱始祖即**望舒**（天选者/月神本体）；唯一后代**望结璘**三千年前在府邸后山一带最早筑屋定居——后山古石台与老树即旧址
- 族谱始祖母永远空白（天选者单体无性繁殖）；长辈只当「月神」是先祖图腾化夸张修辞
- **朔夜不在族谱中**：12 岁时自己要求删除，因登记名「望朔夜」让他觉得怪——离经叛道的具体注脚，与无姓氏风气同源
- 有祠堂、有族务，态度松弛；过年不强求全员到齐，但常住人口足以维持府邸活跃
- 长辈对外来小客极度热络（红包、夹菜、当「可爱晚辈」宠）——文档写建筑时要留出这种烟火气发生的空间

### 小说剧情对空间的硬需求（《归客照清辉》）

1. **大堂**：除夕团圆家宴，热气腾腾的年夜饭长桌，全族老少齐聚
2. **宽阔庭院**：零点新春烟花，能照见层峦叠嶂的飞檐黛瓦
3. **藏书阁**：世代保存古籍，存有《承明古志·月神纪》翻本，望舒在此对账辟谣
4. **后山**：依山傍水的**古老石台与老树**（望结璘定居旧址）；晚辈饭前散步道
5. **回廊**：朱红「美人靠」，守岁倚栏看烟花的落位
6. 亭台楼阁、水榭回廊的整体气象：规模要有「村落感」，纵深足够四人漫步指认故地
