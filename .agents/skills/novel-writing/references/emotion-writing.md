# 情绪传递（写小说就是写情绪）

小说让人废寝忘食、读完久久回味的根本原因：成功调动了读者的情绪。桥段老土、情节不新颖都不要紧，读者照样跟着角色又哭又笑——情绪到位即可。用于：诊断"主角受挫读者无感"的苍白文本、设计情绪冲击点。

判断标尺：余华《活着》单看情节简介像"刻意堆砌苦难"，真读时读者哭得比主角还惨——因为展示的是深植于苦难的生命韧性。**情绪真实，套路也能动人；情绪缺席，奇情也是白纸。**

## 五个方法

### 1. 细节展现：让读者自己感受，不给结论

- 身体反应：紧张手心出汗、愤怒身体发抖、恐惧心跳加速——情绪必有生理反应。
- 行动与姿态：沮丧步履沉重、兴奋手舞足蹈、犹豫搓手踱步、愤怒摔打东西。
- 范本：《活着》福贵得知儿子有庆死后，不写悲痛欲绝，只写——"福贵看着弯曲着通向城里的小路，听不到我儿子赤脚跑来的声音，月光照在路上，像是撒满了盐。"（技术细节见 `show-dont-tell.md` 情绪反应链、`verb-craft.md`。）

### 2. 巧用角色视角：让读者"成为"角色

- 用角色的爱恨、偏见、记忆和期望去感知世界，读者理解角色时情绪才真实强烈。
- 进阶手法：给反派一段视角回忆其一生，读者代入了他的经历，自然共情他为何走到这一步（视角规则见 `narrative-perspective.md`）。

### 3. 构建冲突：情绪在冲突中爆发

- 给角色明确目标 + 制造阻碍的反派 = 冲突。
- 加码关键：让读者看清失败的代价（钱财、爱人、生命、自由），他们才会不自觉替主角着急（联动 `reader-anticipation.md` 的"风险明牌"）。
- 范本：《肖申克的救赎》——蒙冤入狱→目标是自由→爬过污秽下水道在暴雨中仰天呐喊。读者积累的压抑随主角一起释放。**情绪爆发力 = 此前冲突与压抑的积累量。**

### 4. 留白与停顿：关键情绪点不说尽

- 范本：《边城》结尾"这个人也许永远不回来了，也许'明天'回来！"——不确定的收束让读者投入更多情感去悬想。（手法见 `art-of-omission.md`。）

### 5. 对话的力量：欲说还休

- 用语气、语速、停顿、重复与潜台词揭示真实情感；欲言又止与突然沉默胜过千言万语。
- 范本：《红楼梦》黛玉临终："宝玉，宝玉，你好……"——话未说完香消玉殒，怨恨、委屈、爱恋、绝望、不甘尽在这半截话里。（手法见 `art-of-omission.md` 对话留白。）

## 诊断要点

- 情绪是否靠旁白宣布（"他很悲伤"）？→ 换身体反应 + 动作姿态
- 反派是否工具化？→ 给一段反派视角，情绪立刻立体
- 冲突是否无代价感？→ 摆明失败会失去什么
- 高潮是否情绪铺垫不足就引爆？→ 先积累压抑，再释放
- 关键情绪点是否说太满？→ 留白、停顿、半截话

总纲：写小说就是写人，写人的情感。故事可以虚构，情感必须真实——作者真诚投入，读者才能感受到那份力量。
