# 主线构建：问题驱动法

用于：搭建小说主线、拯救"散架/流水账"的文稿、复活弃坑作品。比"英雄之旅""三幕剧"更易落地，核心一句话：**围绕一个核心问题，不断提出问题、解决问题。**

## 第 0 步：理解主线不是直线

主线不是 A 到 B 的事件流水账。反例：《西游记》若写成"第一回收悟空，第二回收白龙马……"的通关攻略无人愿看；真正的主线是"取经团队如何战胜心魔"——悟空戴金箍是学会克制，八戒贪吃是人性写照。**当每个支线都成为主线的镜像，情节就有了光彩。**

## 四步流程

### 1. 找到核心问题

核心问题必须是足够吸引人、能勾起读者好奇心的那个问题，三选一：

- **悬念**：谁是凶手？宝藏在哪里？主角能不能活下来？
- **冲突**：主角如何对抗邪恶势力？相爱的人如何克服阻碍？主角如何在困境中成长？
- **目标**：主角如何实现梦想？如何拯救世界？如何找到真爱？

### 2. 提出一系列小问题

围绕核心问题不断问"为什么"，分三层：

- **背景层**：故事发生在什么时代？主角有什么样的过去？反派有什么样的动机？
- **情节层**：主角会遇到什么困难？会得到谁的帮助？会做出什么选择？
- **人物层**：主角有什么样的性格？有什么样的弱点？会和谁产生冲突？

约束：小问题必须能逐步揭示核心问题的答案、推动故事发展，不为提问而提问。

伏笔联动：小问题同时是细节伏笔的源头。例：主角为什么害怕电梯？为什么总戴着旧手表？答案编织成隐形的网，所有细节成为童年创伤的关键伏笔（配合 `foreshadowing.md` 的伏笔台账管理）。

### 3. 解决问题，推动情节

每写一个情节 = 解决一个小问题。解决问题的过程就是情节发展的过程：

- **设置障碍**：让主角遇到各种困难，增加紧张感，逼主角用尽全力。
- **制造冲突**：让主角与反派、与其他角色产生冲突，并设计平息冲突的方式。

### 4. 串联问题，形成主线

小问题都解决得差不多时，把解决过程串联成一条完整故事线，主线即成。

## 示范模板（悬疑）

核心问题："谁是凶手？"

1. 问：死者是谁？什么背景？→ 答：调查发现死者是富商，仇家众多。
2. 问：死者死前见过谁？有何异常？→ 答：监控显示死前与神秘人见过面。
3. 问：神秘人是谁？与死者什么关系？→ 答：追踪行踪，发现他竟是死者的……

提问→解答→新提问，链条滚动，主线自然展开。

## 诊断要点

- 文稿是否散、像流水账？→ 检查是否存在一个统摄全局的核心问题
- 支线是否与主线无关？→ 让支线成为主线的镜像/折射
- 是否有为提问而提问的注水情节？→ 砍掉不揭示核心问题答案的支线
- 弃坑作品复活法：用提问方式重新审视已有情节，从第一个"为什么"重新开始
